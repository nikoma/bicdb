# BicDB 1.0.330-beta

## Restore Block-Max WAND priority for multi-term BM25

- Runs document-order Block-Max WAND before the optional impact-ordered
  sidecar for exact multi-term conjunctions.
- Keeps impact-ordered retrieval as a compatibility fallback when the
  document-order path is unavailable.
- Prevents broad production queries from exhaustively streaming impact data
  when Block-Max WAND can seek and prune the same exact result set.
- Adds a regression test proving that multi-term BM25 remains on the primary
  document-order path even when an optional impact sidecar is unavailable.

This is a query-routing change only. It does not change the storage format or
require rebuilding an existing full-text index.
