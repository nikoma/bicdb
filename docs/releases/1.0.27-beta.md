# BicDB 1.0.27-beta

Release date: 2026-08-03

## Bounded tiered provider retry

- Adds explicit maximum attempts plus initial and maximum exponential backoff
  limits to tiered extent hydration.
- Retries only transient I/O classes such as timeout, backpressure, interruption,
  connection reset/abort/refusal, and disconnected transport.
- Gives every attempt a fresh staging file and removes failed partial responses
  before waiting, preventing cross-attempt byte contamination.
- Fails integrity, missing-object, descriptor, policy, and other deterministic
  errors immediately instead of amplifying them into retry storms.
- Exposes provider retry totals in cache operational snapshots.
