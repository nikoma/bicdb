# BicDB 1.0.55-beta

Release date: 2026-08-03

## Automatic low-priority replica integrity sweeps

- Adds a checksummed, atomically checkpointed per-node anti-entropy sweep
  controller with deterministic restart-stable range cursors.
- Restricts automatic work to locally led, non-relocating ranges below an
  explicit QPS ceiling; the safe default selects only ranges reported idle.
- Exposes scan, run, cadence, QPS, fence, state, and resource bounds through
  `PgWireConfig`, adopting changes only when no durable work is active.
- Checkpoints an exact cluster/range/epoch/replica/placement-bound fence plan
  before any voter RPC.
- Recovers safely across plan, quorum-fence, digest-schedule, release, and local
  cleanup crash boundaries.
- Defers before fencing and between bounded steps while real server queries,
  reads, or writes are active or queued.
- Admits every fence and digest step through the anti-entropy resource lane
  without consuming reserved consensus and foreground-write headroom.
- Advances at most one bounded step per due supervisor tick and avoids idle
  checkpoint fsyncs before the durable due time.
- Delays the first sweep on a new server by one configured sweep interval and
  rolls back in-memory controller mutations after any failed tick.
- Releases healthy and inconclusive runs through the exact quorum evidence;
  divergent replicas retain the durable fence and require certified repair.
- Adds regression coverage for foreground deferral and restart, epoch/replica
  drift, multi-replica divergence, and fence retention.
