# BicDB 1.0.499-beta

Adds signed ABI feature `authenticated_principal` and read-only native
`auth.current_principal()`. The strict zero-argument call returns exact verified
String subject, effective roles/scopes, and optional String tenant/workspace from
the existing ActorContext. It never parses a numeric id or invents issuer claims.
Anonymous actors fail closed. `auth.current_user()` numeric behavior is unchanged.
Cell refuses this unqualified feature; ordinary-native runtime qualification is
separate from compiler/SDK admission.

Immutable-reference guard refusals now include bounded owner/importer/reference/
subject-resource/guard-name identifiers. Guard comparisons and admission semantics
are unchanged; diagnostics include no expressions, row data or actor claims.

This source note does not claim a published binary, deployment, completed runtime
qualification or ERP product release.
