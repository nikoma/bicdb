# BicDB 1.0.364-beta

Two client-facing correctness fixes found while rebuilding the TPC-C
benchmark seed on current main, plus benchmark-harness plumbing.

- pgwire no longer drops a connection whose message pauses mid-transfer. The
  250 ms socket poll used to interleave NOTIFY delivery also governed the
  length and payload reads after a message tag had arrived, so a large
  statement from a slow or CPU-starved client failed with "Resource
  temporarily unavailable". In-flight messages now wait through poll
  timeouts (bounded by a 30 s budget) in both the synchronous and async
  readers; a regression test sends a query in five pauses.
- A bare `ANALYZE` from a non-superuser now behaves like PostgreSQL: it
  analyzes the tables the caller owns and skips the rest, instead of being
  refused outright. The per-table ownership gate that keeps foreign
  statistics out of `pg_stats` is unchanged.
- `bench/tpcc/run_trial.sh` accepts `EXTRA_ENV` for experimental arms and
  `bench/tpcc/build_seed.sh` gives the seed server two-hour statement
  timeouts so the final schema-statistics step cannot discard a finished
  load.
