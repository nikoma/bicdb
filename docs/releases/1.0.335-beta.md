# BicDB 1.0.335-beta

This release adds PostgreSQL-compatible `split_part` support for application
queries, including the EHR Hub activity feed.

## PostgreSQL-compatible SQL behavior

- Implement `split_part(text, text, integer)` with PostgreSQL-compatible
  one-based and negative field indexes.
- Return an empty string when the requested field does not exist and preserve
  PostgreSQL behavior for empty and multibyte delimiters.
- Propagate `NULL` inputs and reject field position zero with SQLSTATE `22023`.
- Infer the function's text return type and require an integer third argument
  during parameter typing.

## Validation

- Added scalar regressions for positive, negative, missing, empty-delimiter,
  multibyte-delimiter, `NULL`, and zero-field behavior.
- Added an end-to-end SQL regression for the EHR activity-feed query shape,
  including a quoted `current_user` JSONB column and a table alias.
- BicDB SQL focused tests: 2 passed.
