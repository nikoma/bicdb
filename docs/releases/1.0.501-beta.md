# 1.0.501-beta: one-peer-loss witness waits for a briefly held latch

The one-peer-loss convergence test read a follower's state through a
non-waiting latch attempt and failed with "actual target service busy during
diagnostic" when the node's own background worker held the latch at that
instant. This failed the serial native multi-node job once on the head that
became 1.0.499-beta (208 passed, 1 failed), after two clean runs on the
preceding heads.

The test's diagnostic read now waits up to two seconds for the service latch
and the database read lock. No product code or assertion changed.
