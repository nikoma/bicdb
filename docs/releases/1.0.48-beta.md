# BicDB 1.0.48-beta

Release date: 2026-08-03

## Authenticated schema-stage distribution

- Advances the cluster data protocol to version 16 with signed schema staging.
- Adds host-configured schema signing keys and stage limits to data-node
  services; the default service grants no schema signing authority.
- Accepts stage requests only from the current metadata leader over the
  existing member- and certificate-bound cluster transport.
- Restricts destinations to active metadata voters.
- Verifies signatures on the destination against its own trust store and uses
  destination host time for the durable stage record.
- Returns and validates a bounded receipt containing the stage ID, base and
  target fingerprints, and durable stage checksum.
- Makes lost stage requests idempotent without returning the complete bundle in
  the response.

Quorum-wide coordination and activation remain pending.
