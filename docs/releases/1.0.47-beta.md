# BicDB 1.0.47-beta

Release date: 2026-08-03

## Signed cluster schema staging

- Adds domain-separated Ed25519 signatures for bounded cluster schema bundles.
- Recomputes the executable-schema fingerprint from bundle contents instead of
  trusting the supplied fingerprint.
- Adds explicit trusted-key, durable-state byte, and change-count boundaries.
- Stages strictly additive plans on non-empty nodes without mutating their live
  schema, rows, indexes, or advertised fingerprint.
- Rejects untrusted signatures, tampering, collection/index/structural
  replacement, and implicit contraction before writing stage state.
- Persists checksummed stage state atomically with no-follow file validation,
  idempotent lost-response recovery, reopen verification, and safe discard.

Fleet distribution and coordinated activation remain pending and are not
claimed by this release.
