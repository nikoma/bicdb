# BicDB 1.0.343-beta

This release makes optimistic CRUD updates compatible with Carrier's normal
`@version` request contract while preserving BicDB's existing `If-Match`
support.

## Carrier-compatible application behavior

- Accept a resource's optimistic version in the PATCH or existing-record
  upsert JSON body.
- Remove the version token from the writable field patch before capability
  enforcement, then increment the runtime-owned version after validation.
- Reject conflicting body and `If-Match` versions instead of choosing one
  silently.
- Describe the body version field and optional `If-Match` alternative in the
  generated OpenAPI contract.

## Validation

- Added body-version success and stale-version conflict coverage to the
  application resource runtime suite.
- Added header/body mismatch and generated OpenAPI assertions.
