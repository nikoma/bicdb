# BicDB 1.0.312-beta

## PostgreSQL 18.4 migration compatibility

- Preserve statement boundaries when extension and advisory-lock syntax appears in multi-statement migration batches.
- Accept multiline routine declarations, schema-qualified `current_user()` calls, and leading comments before `ALTER DEFAULT PRIVILEGES`.
- Match PostgreSQL's default unlimited `statement_timeout` while retaining explicit timeout cancellation.
- Add PostgreSQL-compatible function and table privilege inquiries, including routine OIDs, schema-qualified tables, comma-separated privilege lists, and boolean result metadata for prepared queries.
