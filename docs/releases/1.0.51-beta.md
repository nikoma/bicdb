# BicDB 1.0.51-beta

Release date: 2026-08-03

## Quorum-committed schema activation fence

- Builds an exact next-generation topology candidate only after every frozen
  metadata voter has durably staged the signed additive target.
- Changes all voter schema-digest labels from the common base to the signed
  target in one topology generation.
- Gives the fence authority only through the existing metadata-consensus
  proposal and quorum-commit path; an uncommitted candidate changes nothing.
- Reuses the strict live-versus-published schema fence so old-schema nodes stop
  production writes and cluster data RPC until local activation completes.
- Rejects membership, topology, leader, base, voter-state, digest, or active
  range-relocation drift.
- Reconciles a lost proposal response or coordinator/leader restart from the
  exact committed topology and checkpoints the fence generation durably.
- Preserves compatibility with pre-fence rollout checkpoints by omitting the
  new optional field until a fence is committed.

Authenticated activation RPC, all-voter completion receipts, cleanup, and a
compatibility window without a write pause remain pending.
