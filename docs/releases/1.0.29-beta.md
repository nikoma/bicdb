# BicDB 1.0.29-beta

Release date: 2026-08-03

## Read-only tiered buffer pools

- Adds the bounded `PageReadSource` contract for buffer-pool miss resolution.
- Makes `TieredPageReader` a page source for generation-pinned snapshots and
  read-only followers.
- Retains the ordinary preallocated, sharded, scan-resistant page budget while
  sourcing durable bytes from immutable extents.
- Rejects writable guards fail-closed for a non-local source, preventing a
  modified page from later being shadowed by an older checkpoint copy.
- Validates page-count and page-size compatibility at construction and exposes
  read-only mode in buffer-pool operational snapshots.
