# 1.0.523-beta: BicDB is licensed under Apache-2.0

1.0.522-beta is reserved by a parallel candidate and is not used here.

## License change

The project license changed from the custom BicDB License 1.0
(`LicenseRef-BicDB-1.0`, Apache 2.0 with three additional restrictions on
managed database services, database-product/OEM sales and console
white-labelling) to the **Apache License, Version 2.0** (`Apache-2.0`),
unmodified. The restrictions and their scope notice are removed. The repository
owner directed this change.

The root `NOTICE` now reads:

```text
BicDB
Copyright 2026 WalkNorth Inc. and Nikolai Manek
https://bicdb.com

BicDB is licensed under the Apache License,
Version 2.0.

Original software developed by WalkNorth Inc. and Nikolai Manek.
```

Copies received under an earlier license keep the grants they were received
with. Earlier release notes and evidence are not rewritten.

## What changed

- `LICENSE` is now the verbatim Apache License 2.0 text (identical to
  `LICENSES/Apache-2.0.txt`).
- Every Cargo package declares `license = "Apache-2.0"` through the workspace
  `license` key; `license-file` is no longer used. Every package ships
  `LICENSE`, `NOTICE` and `THIRD_PARTY_NOTICES.md` identical to the root copies;
  `web/bicdb-client`, `abi`, `examples` and `jepsen` ship identical `LICENSE`
  and `NOTICE`.
- Removed: `LICENSE-SCOPE.md` and its per-package copies, the per-package
  `LICENSES/` and `licensing/NOTICE-Apache.txt` copies, `licensing/NOTICE-Apache.txt`,
  the never-adopted `licensing/contributor-agreement.draft.md`, and the
  commercial-licensing page, licensing transition record and licensing
  implementation report under `docs/`.
- `deny.toml` drops the first-party custom-license clarifications and exceptions.
- `licensing/transition.toml` now records Apache-2.0, the license hash and the
  `package_paths` that ship copies.
- `scripts/validate-license-transition.py` and `scripts/sync-package-licenses.py`
  (run by `scripts/validate-licensing.sh` in the "Licensing invariants" CI job)
  now enforce: verbatim hash-pinned Apache `LICENSE`, the exact `NOTICE` text,
  Apache-2.0 on every package and manifest, no custom-license carve-outs in
  `deny.toml`, no tracked file outside historical records naming the retired
  identifier, Apache-2.0 in every SPDX header, identical packaged copies with no
  retired legal files, and resolvable links in licensing documents.
- The CLI release packager ships `LICENSE`, `NOTICE` and
  `THIRD_PARTY_NOTICES.md` (no scope file); the Rails demo image likewise.
- README states that BicDB is free and open source under Apache-2.0.
  CONTRIBUTING, CHANGELOG, the licensing guide, packaging rules, browser-client
  licensing page and third-party notices describe Apache-2.0. Contributions are
  received under Apache section 5, with no contributor license agreement or
  sign-off requirement.

## Not changed

No code, build, dependency or runtime behaviour changes. No binary, release or
deployment is produced by this source version.
