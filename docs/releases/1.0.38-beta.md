# BicDB 1.0.38-beta

Release date: 2026-08-03

## Certified anti-entropy completion

- Rebuilds each verified source bucket's Merkle summary from immutable staged
  records with the same hash chain used by full range digests.
- Requires original authenticated manifests for every report node and exact
  verified-bucket coverage for every divergent voter.
- Reconstructs each repaired voter's complete range root and refuses
  certification unless it equals the quorum-certified source root.
- Bounds replica count, bucket evidence count, digest fanout, and certificate
  bytes; atomically persists checksummed certificates with no-follow reads.
- Adds a repair-specific fence-release API that requires certificate cluster,
  session, range, epoch, prefix, quorum, and covered nodes to exactly match the
  active durable fence evidence.
- Reuses remote-first, leader-last idempotent fence release so process failure
  during release remains safe to retry.
