# BicDB 1.0.21-beta

Release date: 2026-08-03

## Quorum-committed restore activation

- Adds a compact `MetadataRestoreActivation` control record binding one
  certificate, admission report, backup plan, topology, acknowledged-node
  count, and canonical node-acknowledgement-set hash.
- Adds leader-only restore-activation proposals to metadata consensus. The
  unchanged topology and both old and current voter quorums fence the commit.
- Persists the committed activation in metadata state and snapshots so process
  restart, follower catch-up, and leader failover cannot forget or substitute
  the decision.
- Rejects malformed digests, wrong-cluster/topology decisions, duplicate or
  non-advancing activations, concurrent metadata changes, and activation data
  hidden inside leadership barriers.
- Keeps the existing v1 metadata JSON shape byte-compatible when no restore
  activation exists by omitting all new optional fields.
