# BicDB 1.0.73-beta

This release turns the bounded structural and MVCC verification primitives
into one durable, resource-governed server-paged integrity operation.

## Phase-exact supervision

- Runs structural verification first and atomically checkpoints its valid
  completion before permitting MVCC work.
- Terminates fail-closed on a classified structural fault while accumulating
  MVCC faults through a complete reachable-key sweep.
- Atomically retains both cursors, immutable limits, phase, bounded last
  reports, monotonic totals, scheduling state, and terminal validity.
- Replays the prior read-only cursor after a crash before checkpoint
  publication without skipping work or double-counting accepted evidence.

## Durable and governed operation

- Protects every state with a complete SHA-256 and the immutable store and
  operation IDs shared by paged maintenance.
- Rejects unknown fields, symlinks, unsafe files, size changes, oversized
  state, identity mismatches, invalid phase combinations, and checksum damage.
- Admits each page step through the anti-entropy lane under explicit memory,
  I/O, CPU-slot, and token-charge demand.
- Persists saturation deferral, bounded exponential failure backoff,
  automatic failure pause, and operator pause/resume.
- Fences stale workers by operation ID and refuses a replacement while an
  unpaused run remains active.

## Public integration

- Adds start, status, tick, pause, and resume operations to `BicDb`.
- Validates a first-step tree envelope against the configured page size before
  creating schedule state.
- Embedded-memory mode rejects integrity supervision without writing paged
  maintenance files.

## Verification

Tests cover atomic phase boundaries, lost-checkpoint replay, process reopen
after every step, exact final row/version totals, structural and MVCC fault
evidence, resource deferral before page access, failure backoff, automatic and
operator pause/resume, stale-operation fencing, shared store identity,
checksum/shape/size tampering, invalid initial limits, and embedded rejection.
