# BicDB 1.0.309-beta

Release date: 2026-08-24

## Impact-ordered BM25 for broad queries

- Routes sealed, single-field BM25 retrieval through the existing
  impact-ordered sidecars before falling back to document-order Block-Max
  WAND.
- Extends impact-ordered BM25 to single-term queries, which are the dominant
  web-search shape and previously scanned the full document-ordered posting
  stream.
- Keeps mixed-field generations, mutable tails, and tombstones on the
  compatibility path when impact ordering cannot prove an exact answer.
- Pins single-term and multi-term results bit-for-bit against the established
  document-order implementation across broad and rare terms.

This turns the impact sidecars produced during large sealed builds into the
default exact candidate path instead of leaving them unused by normal BM25
queries.
