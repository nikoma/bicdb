# BicDB 1.0.362-beta

This release completes the nine-stage open-core repository extraction without
changing BicDB's license.

- Finalizes the public/private/product topology and third-party controller
  contract report.
- Closes four pre-existing JSON/composite regressions by making JSONB display
  and key identity independent of Cargo feature unification while preserving
  PostgreSQL `json` field order.
- Makes canonical application telemetry, lifecycle extensions, encryption
  requests, JWT key-version headers and named-blob metadata BicDB-neutral while
  retaining explicit read compatibility for durable legacy spellings.
- Moves the remaining ERP-shaped production runbook to the product integration
  repository and extends the architecture gate over canonical root documents
  and runtime emitters.
- Records the complete public, private-platform and product-integration
  validation matrix in `open-core-extraction-final.md`.

Public BicDB remains complete and independently operable. Fleet-scale
automation is supplied through public APIs by `bicdb-platform` or any third
party. BicDB remains under its existing BUSL-1.1 terms; Apache-2.0 publication
is a separate future event blocked on the readiness register.
