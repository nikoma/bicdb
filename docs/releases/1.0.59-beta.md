# BicDB 1.0.59-beta

Release date: 2026-08-03

## Windowed performance certification

- Advances immutable cluster certification plan, collector state, and report
  formats to version 4.
- Replaces unbounded scalar performance claims with explicit ordered baseline,
  rebalance, and recovery timestamps inside the certification report window.
- Requires baseline and active-rebalance measurement windows to run for at
  least five minutes each.
- Requires at least 10,000 samples for foreground and hotspot p99 in both
  windows before applying the 25% regression gates.
- Requires recovery timestamps to be positive, inside the rebalance window,
  and exactly equal to the reported recovery duration.
- Requires at least 10,000 successful majority-quorum operations and complete
  rejection of at least 1,000 minority-partition write probes.
- Requires relocation of at least 10% of the logical corpus, nonzero source,
  network, and destination byte counters, and no more than 4x aggregate
  relocation-I/O amplification.
- Requires the measurement observation itself to reference exact verified
  resource-sample, workload-latency, and rebalance-timeline artifacts.
- Adds adversarial coverage for short or overlapping windows, insufficient
  samples, inconsistent recovery timing, trivial data movement, quorum or
  minority-policy failures, and artifact substitution.

This release freezes the performance evidence contract; it does not claim the
production 1 TB, 5 TB, or 20 TB measurements have already passed.
