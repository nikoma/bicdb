# BicDB 1.0.46-beta

Release date: 2026-08-03

## Restartable paged B-tree construction

- Replaces paged `CREATE INDEX` row accumulation and one giant backfill
  transaction with explicitly row- and byte-bounded build ticks.
- Writes an unreachable physical generation, checkpoints canonical cursors in
  checksummed atomically replaced state, and idempotently resumes after reopen.
- Re-scans every source row, point-verifies its physical entry, counts the
  complete physical namespace, and detects unique-key duplicates before
  publication.
- Pins the source commit sequence and fails closed after an intervening write,
  preserving every published index and row.
- Publishes by installing the physical alias before the logical catalog's
  atomic visibility point; a crash cannot expose a partial generation.
- Reconciles the narrow post-publication/checkpoint crash window on retry and
  refuses to discard any generation referenced by the logical catalog.
- Serves promoted B-trees directly from paged storage and keeps their complete
  key set out of resident memory, including after reopen.
- Adds safe validated discard for incomplete generations; cleanup advances
  through fixed entry/byte-bounded key pages rather than accumulating an
  entire failed namespace in memory.
- Adds regression tests for bounded restart/resume, non-visibility before
  publish, write fencing, paged cleanup, durable uniqueness, and read-through
  reopen.
