# 1.0.477-beta

Native HTTP resources accept Carrier's one-based `page` and `per_page` parameters
as bounded aliases for `offset` and `limit`. Conflicting aliases, duplicate
pagination parameters, zero sizes/pages and arithmetic overflow are rejected.
Existing resource limits, tenant policies and legacy pagination remain enforced.

Pure native invariant Boolean expressions now short-circuit `false && rhs`,
`true || rhs` and `false implies rhs`. Required right-hand expressions, invalid
predicates and invalid operand types retain their checks. This fixes guarded
nested scans and guarded arithmetic without disabling any invariant or skipping
validation on read-only transactions.

The source incorporates the writable Repeatable Read/Serializable changes in
475 and namespace identity delivery in 476. A source version alone does not
assert a built binary, production qualification, release publication or deployment.

Node qualification drivers:

- `scripts/qualify-native-pagination.mjs`: actual TLS/OIDC resource paging,
  bounds, conflicts, tenant isolation, concurrent edits and crash/cold restore.
- `scripts/qualify-invariant-guards.mjs`: guarded arithmetic, required denials,
  false predicates, operand types, concurrent reservations, tenants and recovery.

Application financial qualification additionally checks exact Decimal reports,
populated upgrades, partial FX settlement, reversing entries and reconciliation.
Retain evidence for the exact final source and binary separately from private
old-main reproductions.
