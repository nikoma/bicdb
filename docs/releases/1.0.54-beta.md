# BicDB 1.0.54-beta

Release date: 2026-08-03

## Write-available additive schema rollout

- Adds a quorum-published additive compatibility window in cluster data
  protocol 19 while retaining the current schema as the active contract.
- Allows production writes and authenticated data RPC during bounded activation
  only when the node proves an exact signed-schema prefix.
- Binds activation RPCs to the exact base and target pair and rejects mixed
  strict-fence/compatibility-window voter topologies.
- Recovers verified compatibility authority from durable stage and activation
  checkpoints after process restart.
- Preserves shadow-index correctness for rows committed before, during, and
  after resumable index construction.
- Requires exact activation-completion receipts from every frozen voter before
  constructing target promotion.
- Promotes the target atomically through a second quorum-committed topology
  generation and rejects finalization before that commit.
- Prevents heartbeats from forging or erasing a pending target, advertising an
  activated target early, or restoring the base digest after promotion.
- Retains restart compatibility for older strict-fence rollout checkpoints.

## Future design

- Adds a vendor-neutral SQL package-module roadmap and detailed initial design
  covering public contracts, private helpers, immutable constants, exact
  signature matching, atomic replacement, dependencies, privileges,
  schema-bundle integration, introspection, and restart certification.
