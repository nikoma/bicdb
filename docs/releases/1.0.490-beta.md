# BicDB 1.0.490-beta

This source batch follows verified main 1.0.489-beta. A source version, built
binary, runtime qualification, signed accounting release and deployment are
separate deliverables. The changes below do not establish HA, Cell or ERP parity.

- Reject application Decimal inputs that cannot be represented exactly, sharing
  the same decoder with native invariant operands and exact SUM source operands.
  Preserve exact scientific/redundant-zero syntax without admitting rounding.
- Execute signed Decimal resource equality/minimum filters with exact typed
  comparisons, including older SDK fields and legacy bracket filters. Retain
  independent authenticated Node before-controls for both input and filter bugs.
- Add checked native Gregorian Date arithmetic and Date comparisons for guards;
  ordinary SQL Date index semantics are unchanged.
- Add immutable owner fact publications and projection-only module dependencies.
  Resolve actual physical ownership from the signed installed catalog, preserving
  tenant, role, append-only, commit and lifecycle boundaries. Descriptor-only
  imports grant no SQL, model or service authority and carry no physical relation.
- Add bounded exact proportional intervals to programs and native guards, with
  strict scalar types, exact half-even prefix arithmetic, explicit runtime
  capability and a sticky old-reader fence. No VM budget or financial authority
  is relaxed. Actual stock and accounting workflow qualification is required.
- Preserve the verified 1.0.489 source delivery notes and exact post-join writer
  registry evidence. The latter records successful scoped CLI controls and
  post-join refusals; it does not claim healthy write continuity or a fix.

The retained first private combined prototype passes its input regression but
fails the separate resource-filter before-control. Those results do not qualify
this changed source revision. Final compiler/native pins, mandatory CI and actual
combined Node workflow/recovery results must be recorded before delivery.
