# BicDB 1.0.20-beta

Release date: 2026-08-03

## Fail-closed cluster restore admission

- Adds offline certificate validation that checks the immutable restored
  topology without mistaking a persisted pre-crash role for a live election.
- Adds `verify_cluster_restore_admission`, requiring exactly every certificate
  artifact node and byte-identical topology snapshots.
- Authenticates and hashes each full `BICBAK03` archive in one bounded streaming
  pass, binding its backup ID, raw encrypted bytes, and manifest to the node
  artifact.
- Verifies storage compatibility, database/page integrity, live schema
  fingerprint, node/cluster identity, metadata term and commit watermark, PITR
  target, range-log progress, and the active plan-owned fence at every
  certified cut.
- Adds a bounded, no-follow, read-only `RangeWriteStore::inspect` path so
  admission cannot migrate or rewrite range consensus metadata while checking
  it.
- Produces an atomic, bounded, checksummed `ClusterRestoreAdmissionReport` only
  after the complete cluster passes. Missing nodes, stale watermarks, schema
  drift, unexpected fences, symlinks, archive substitution, or barrier drift
  fail closed.
- Adds a cheap per-node startup validator bound to the same certificate and
  consensus watermark. Restored write fences remain installed until the host
  completes a separately controlled global activation.
