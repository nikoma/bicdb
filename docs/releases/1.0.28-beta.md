# BicDB 1.0.28-beta

Release date: 2026-08-03

## Generation-pinned tiered point reads

- Adds `TieredPageReader`, a read-only view pinned to one authenticated active
  page-generation manifest.
- Routes page IDs through the ordered extent map and hydrates each owning extent
  under the existing hard cache limits.
- Uses positioned local I/O to copy and verify only the requested page after an
  extent has been admitted, rather than materializing the extent per hit.
- Rechecks the selected page's ID, checksum, and torn-write trailer and evicts a
  corrupt local cache object before permitting provider rehydration.
- Revalidates a restart-discovered cache object's complete content address and
  page layout before allowing its first point read.
- Rejects the mutable superblock, out-of-generation pages, forged detached
  manifest/hash pairs, and incorrectly sized buffers without changing active
  data.
