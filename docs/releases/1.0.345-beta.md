# BicDB 1.0.345-beta

This release fixes PostgreSQL 18.4 parity for strict `round` evaluation over nullable aggregate results.

## Changes

- Return `NULL` for one-argument `round(NULL)` instead of raising an invalid-SQL error.
- Preserve existing non-null one-argument `round` behavior.
- Cover the EHR Digital Twin expression `COALESCE(ROUND(AVG(bigint_column))::bigint, 0)` when the aggregate input set is empty.

## PostgreSQL 18.4 reference

PostgreSQL 18.4 returns a `numeric` average for `bigint`, propagates the empty aggregate through `round` as `NULL`, and lets `COALESCE` produce `0`.
