# BicDB 1.0.77-beta

This release completes the initial server-paged background-worker set with
bounded, governed asynchronous read-ahead.

## Bounded speculative work

- Adds a construction-time hard ceiling for deduplicated page hints; zero
  disables speculation and the implementation rejects more than 65,536 queued
  pages before page storage is created.
- Uses an ordered FIFO map plus reverse index, keeping enqueue, worker removal,
  and foreground cancellation logarithmic in the bounded queue size.
- Limits every worker step by candidate count, conservative logical I/O, and
  cooperative duration.
- Returns exact classified reports and rejects unknown serialized fields or
  internally inconsistent reports.
- Treats hints as disposable derived state. Foreground reads remain
  authoritative and correct when speculation is disabled, saturated,
  interrupted, or unable to read a page.

## Scan-resistant cache admission

- Submits only exact B+ tree leaf-sibling and overflow-chain dependencies; query
  threads enqueue hints without issuing speculative I/O.
- Loads into a free frame or replaces only a clean, unpinned probationary page.
  Read-ahead never evicts protected or dirty pages and never performs
  writeback.
- Requires two real foreground touches before a prefetched page reaches the
  protected queue, preventing speculative scans from displacing the hot set.
- Tracks first use, unused replacement, foreground cancellation, admission
  refusal, and read failure without unbounded identities.
- Restores a fixed frame after any speculative or foreground read failure so a
  repeated bad page cannot shrink the configured pool.

## Production hosting and observability

- Gives the server worker a narrow page-only capability and releases the
  database-wide guard before speculative I/O.
- Admits each step through the node's shared background compaction lane before
  removing queued work. Saturation therefore delays hints without losing them.
- Validates the worker envelope against both the resource governor and the
  opened store's durable page size before accepting traffic.
- Drains continuing work promptly, applies capped exponential failure backoff,
  rate-limits error logs, and interrupts shutdown sleeps in bounded slices.
- Advances the strict paged-storage snapshot contract to format version 4 and
  exposes fixed-cardinality queue, usefulness, failure, cancellation, and stop
  counters.

## Verification

Tests cover queue deduplication and capacity, zero-capacity operation,
foreground cancellation, candidate/I/O/duration limits, delayed reads, read
errors and frame restoration, dirty/protected-page safety, two-touch promotion,
unused-prefetch accounting, hot-set scan resistance, exact B+ tree and overflow
producers, governor saturation and permit release, durable-page-size validation,
automatic server draining, shutdown interruption, snapshot metrics, complete
page-storage integration suites, and full-workspace all-target compilation.
