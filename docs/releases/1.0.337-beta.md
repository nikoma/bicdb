# BicDB 1.0.337-beta

This release makes non-recursive common table expressions feeding
`INSERT ... SELECT` behave like PostgreSQL, including Carrier audit-log writes
used by Cell applications.

## PostgreSQL-compatible SQL behavior

- Materialize non-recursive CTEs before executing an `INSERT ... SELECT` body.
- Reuse BicDB's existing CTE-aware insert path instead of rejecting the query
  as unsupported.
- Preserve recursive-query handling in the SQL engine.
- Fix the WalkNorth EHR prescription workflow's append-only audit write.

## Validation

- Added a regression covering two chained CTEs feeding an insert-select into a
  Carrier-shaped audit table.
- Reproduced the complete prescription request against PostgreSQL 18.4 (HTTP
  200) and BicDB 1.0.336-beta (HTTP 400) before the fix.
- Verified the focused BicDB SQL regression passes.
