# Native logical-history producer checkpoint

This unmerged internal component separates a common logical history from local receipt identity. Actual empty-genesis publication writes H0 and its immutable index-zero entry in the same native page transaction. H0 binds cluster/bootstrap, range/span, portable schema/catalog, reader features and the actual empty image, and excludes local birth/node/namespace UUID, DB sequence and local history generation. Every actual Applied prefix completion writes its immutable original-command-checksum link and latest native prefix atomically. Local history-generation UUIDs are storage pointers and are excluded from the common hash.

Hidden genesis/prefix receipt format 2 refuses earlier prototype contracts. The source lineage validates actual generation/head and exposes bounded native export: at most 256 entries and 256 KiB per step, contiguous actual links, cancellation and before/after local revalidation. An opaque install-safety history point preserves irreversible history even when source visibility is invalidated; a separate immutable-record check permits an authorized install's own invalidation-generation changes without erasing lower bounds.

Two independent local DB directories with different actual birth/node IDs, namespace UUIDs, local generations and receipt hashes produced the same H0/H. The real RF1 originating coordinator exported actual history 0..2 in one-entry chunks with matching links/head. A pure hash test confirms different Applied command checksums fork and canonical Aborted ignores uncommitted prepared variants; this test grants no abort authority, and no actual quorum-abort producer is implemented here.

These are local fsync/native data tests, with core optimization disabled and optimized dependencies; they are not a multi-host or fault qualification run.
