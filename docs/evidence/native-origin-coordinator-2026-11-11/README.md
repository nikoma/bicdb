# Native originating coordinator boundary

This unmerged internal batch connects originating native transactions to the actual range coordinator, native pending journal and private WAL receipt. Borrowed DB context avoids reacquiring a caller-held DB lock. Ordinary native row writes require an owned, armed transaction scope that is published only after durable pending persistence; a generic public admission ticket cannot substitute. Scope ownership is bounded and grants no range floor or quorum authority.

The sender collects distinct certificate replies before issuing any native replica Apply. On local WAL completion it records materialized pending, then installs the native prefix only with the actual certificate quorum and matching current-open transaction/mutation receipt. A failed or missing certificate leaves an uncertain outcome and the older certified floor. The remote authenticated-leader producer is **not connected yet**; bare native Apply explicitly refuses, and native startup preserves CQ history instead of replaying it through the legacy raw apply path.

The actual RF1 coordinator test uses a real fsync range catalog and core transaction under an outer DB write guard. It completed without recursively acquiring that lock. An injected post-admission/pre-WAL failure returned `CommitOutcomeUnknown`, released row/transaction ownership before volatile admission release, permitted a fresh bounded freeze, retained the unresolved raw log/native pending through reopen, and applied no row. No durable abort or aborted outcome receipt replaces the distributed decision.

A transaction-owned release guard covers failed local attempts and drop. The release callback only removes volatile coordinator ownership and invalidates cached recovery readiness; it does not mutate rows or abort the durable command. Synchronous page/data guards have unwound before this release. Deferred materialization subsequently flushes WAL/page markers rather than applying rows; materialization failures fence the DB. Full asynchronous fault qualification remains required.
