# BicDB 1.0.31-beta

Release date: 2026-08-03

## Range-fenced live digest scans

- Connects bounded Merkle state to the live `server_paged` range scanner one
  record/byte-bounded step at a time.
- Requires the authenticated current leader, a local voting replica, the exact
  durable fence owner, range epoch, token interval, and resolved consensus
  prefix before every step.
- Rechecks the fence immediately before checkpoint mutation and rejects
  missing, replaced, expired, future-dated, or unresolved-prefix fences without
  advancing state.
- Reuses the relocation cursor and adds fingerprinted, idempotent collection
  advances so empty collections resume safely.
- Keeps authority selection and record repair out of the local scan surface;
  those require the forthcoming quorum-certified orchestration layer.
