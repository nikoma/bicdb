# 1.0.517-beta source candidate: commit visibility completion

This candidate changes ordinary commit completion so an exhausted original
five-second visibility wait cannot become a successful ACK. It retains the
actual transaction identity and required post-commit obligations, preserves
committed SQL DDL/settings on a completion error, and keeps native local
materialization separate from an ordinary global-visibility proof.

The reviewed implementation snapshot is
`526543fd481e47d09d3af6de16ebc1fe46f44d30`, integrated on runtime source
`881087806b3a5a9792b3e0ba46ba1ba1f2dd0617` and ledger source
`bb33a0dcf948de053931b691fa6260e5bfa74c5b`. Those parent candidates have their
own CI results; no parent result establishes acceptance of this changed source.

Memory workers defer reads below their recorded source floor and retain
observed derived-write uncertainty without ordinary replay. A mandatory durable
reader feature precedes publication of new Unknown job metadata. Actual per-job
claims and fresh status checks prevent stale cohorts from reusing an unresolved
job; fixed-limit selection skips existing claims so other eligible jobs can run.

At preparation, eight Core scheduling/failure controls, one native INITIAL RF3
component and one public-SQL post-commit error control are **test definitions,
not executed results**. Static/source checks do not prove crash durability,
same-original recovery or five-node operational failover.

[The full design and limits](../design/commit-visibility-completion-issue205.md)
include the remaining cold job-attempt handoff gap, same-original uncertain-job
reconciliation, existing worker snapshot behavior and strict catalog cleanup
that can still refuse. The SQL control does not prove atomic source-plus-derived
indexing or rollback-on-error. Claim-held worker progress does not qualify stalled
storage or range relocation.

The original failed Azure experiment and all failed PR203/204 evidence remain
unchanged. This candidate does not implement a general distributed SQL
coordinator, transparent cross-range SQL, complete automatic native relocation
or production admission. A source version does not publish a binary or release.
