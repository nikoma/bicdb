# BicDB 1.0.52-beta

Release date: 2026-08-03

## Authenticated all-voter schema activation

- Adds the bounded signed-schema activation RPC in cluster data protocol 17.
- Requires the authenticated caller to be the current metadata leader and the
  published topology to equal the committed consensus generation.
- Rejects activation before the exact all-voter target-digest fence is committed.
- Revalidates destination-local trust, stage identity, target, and resource bounds.
- Returns progress or completion receipts bound to the node, rollout, stage,
  activation checkpoint, target digest, live digest, and durable state checksum.
- Advances at most one local activation step per request and one voter at a time
  in the rollout coordinator.
- Retries lost responses against idempotent node-local checkpoints and resumes
  coordinator activation after restart.
- Declares the rollout complete only after durable completion evidence exists
  for every frozen metadata voter.
- Preserves existing rows while applying strict additive schema changes.

Fleet-wide verification and cleanup and an availability compatibility window
without a whole-cluster write pause remain pending.
