# BicDB 1.0.354-beta

This release establishes the first open-core dependency-inversion seam.

- Adds the public `PgWireHostService` lifecycle contract and
  `PgWireHostContext` mechanism surface for controller implementations.
- Makes the generic pgwire serving APIs controller-free by default.
- Preserves the BicDB CLI's existing automatic distribution behavior through
  explicit service injection rather than protocol-layer construction.
- Moves the `redb` and `fjall` comparison engines behind the explicit
  `bench-comparison-engines` feature so production CLI builds do not link them.
- Adds regression coverage for explicit, duplicate-safe host-service startup.

The repository remains under its existing license; this release does not
perform the proposed Apache-2.0 relicensing.
