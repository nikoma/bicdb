# BicDB 1.0.318-beta

This hotfix makes pgwire admission failures deterministic at the TCP boundary
and closes storage-lock and MVCC lifecycle races found by the post-main full
matrix. It follows the Phase-2 cryptographic Cell release without changing Cell
data, manifest, encryption, or application semantics.

## Fixed

- A connection refused by `--max-connections` or
  `--max-connections-per-ip` now sends its PostgreSQL `FATAL 53300` frame,
  half-closes the write side, and briefly drains the already-sent startup
  packet. On Linux, closing a socket with unread peer bytes can otherwise emit
  an RST and discard the queued error frame, leaving clients with
  `Connection reset by peer` instead of the actionable SQLSTATE.
- Rejection drains are bounded by `--max-pending-accepts`, by
  `--max-request-bytes`, and by a 250 ms deadline. When that budget is full,
  the accept loop applies backpressure and performs the bounded drain inline
  without creating an unbounded task population.
- The regression test now exercises sixteen consecutive same-IP refusals and
  requires every client to receive `FATAL 53300`.
- Unix directory ownership now combines a non-fork-inherited process record
  lock with an inode-scoped in-process guard. A concurrently spawned child can
  no longer retain `paged/store.lock` after the owning database has completed
  `close()`, while second handles, second processes, and crash recovery retain
  their existing fail-closed behavior.
- MVCC version-chain garbage collection is now capped at the contiguous applied
  watermark. A session-local read-your-own-write snapshot can no longer prune
  the only row version that newly connected sessions are still entitled to see
  while lower commit sequences remain in flight.

## Validation

- targeted repeated pgwire refusal regression;
- deterministic fork-inheritance, concurrent-open, and repeated-kill lock
  regressions;
- deterministic out-of-order-commit MVCC garbage-collection regression;
- parallel spatial CLI suite with immediate server-paged reopen;
- full locked pgwire suite;
- workspace/all-target compile;
- formatting and licensing invariants;
- GitHub pull-request and post-merge `main` workflows.
