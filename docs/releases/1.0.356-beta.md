# BicDB 1.0.356-beta

This release separates public database mechanisms from controller policy.

- Adds the public `ClusterPlacementPlanner` policy interface.
- Makes the existing supervisor consume an injected placement planner before
  applying independently validated rebalance plans.
- Keeps topology ownership, relocation state, fencing, transport contracts,
  cancellation and operational metrics inside BicDB.
- Extends `PgWireHostContext` with graceful background-task accounting,
  shutdown-aware waiting and validated topology installation for out-of-tree
  controller services.
- Adds regression coverage proving a replacement placement policy is invoked.
- Documents the mechanism/controller split across distribution, HA/DR,
  backup, schema rollout, anti-entropy, compliance, query, routing and Cells.

The repository remains under its existing license; this release does not
perform the proposed Apache-2.0 relicensing.
