# BicDB 1.0.40-beta

Release date: 2026-08-03

## Resource-governed anti-entropy scheduling

- Adds a durable scheduler around each quorum-fenced range digest run.
- Admits every due step through the anti-entropy resource lane before issuing a
  replica RPC, with explicit peak memory, I/O, CPU, and rate demand.
- Limits each tick to one replica step and defers saturation without touching
  the transport.
- Atomically checkpoints run progress, due times, capped exponential failure
  backoff, terminal pauses, and completion in one checksummed file.
- Recovers uncertain remote progress through the digest run's existing
  compare-and-advance protocol after a process restart.
- Rejects clock regression, symlink state, changed limits, corrupt checksums,
  unbounded errors, expired fences, and invalid operator resume times.
