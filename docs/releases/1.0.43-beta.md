# BicDB 1.0.43-beta

Release date: 2026-08-03

## Governed distributed reads and bounded metrics

- Adds foreground-read admission before distributed scatter/gather contacts a
  shard or creates its bounded worker pool.
- Requires declared memory for result bytes and fixed per-shard metadata,
  in-flight I/O for concurrent responses, CPU for actual workers, and rate
  tokens for the bounded result maximum.
- Proves saturation and under-declaration execute zero shard calls and that
  successful fan-out releases its permit after merge.
- Exposes Prometheus text with exactly three fixed aggregate scopes and seven
  fixed lane labels; user-controlled identifiers cannot affect cardinality.
