# 1.0.528: the directory-lock probe compiles on macOS

The directory-lock probe in `bicdb-page` compared the `flock` lock type with
`F_UNLCK`. Linux declares `F_UNLCK` as `c_int`, but macOS and the BSDs declare
it as `c_short`, so the crate did not compile on macOS (`cargo install bicdb`
1.0.525 failed there). Both sides of the comparison are widened to `i32`;
behaviour on Linux is unchanged.

The same fix was published to crates.io as 1.0.527, built from the 1.0.525
sources. This version carries it on `main`.
