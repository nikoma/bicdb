# 1.0.478-beta — HA/recovery evidence publication

This source update publishes the [revision-scoped recovery evidence matrix](../recovery-component-evidence-2026-11-11.md).
It adds no runtime implementation beyond its 1.0.477-beta parent. Experimental
engine patches are retained as inert evidence, not activated source.

The new receipts distinguish local native read observations, authenticated but
unadmitted read-quorum candidates, catalogue fsync safeguards, and a reproduced
unsupported interrupted-image cold resume. The latter is a **failed recovery
scenario**, despite its passing characterization test. Source data and its
acknowledged value survived; the partially installed target could not contribute
to the required fresh data quorum. It is not attributed to the original Azure
failure.

The publication also restores one exact 127-byte historical UI log omitted by
Git ignore rules from the source-475 evidence merge. All 42 artifacts now match
that original manifest; the omission did not change tested runtime code.

The [original failed Azure qualification](../azure-scale-out-results-2026-11-11.md)
and production gate are unchanged. StrongGet, integrated cold-resume repair,
automatic fault-safe four-to-five relocation, sustained capacity gain after
convergence, and general transparent distributed SQL remain unqualified. No
new VM campaign, release binary or deployment accompanies this documentation
version. Historical test versions, failures and binary hashes remain unchanged.
