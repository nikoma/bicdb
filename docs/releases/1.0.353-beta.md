# BicDB 1.0.353-beta

This release establishes the validated baseline for BicDB's staged open-core
extraction.

## Changed

- Added the repository-wide open-core extraction audit and progress ledger.
- Repaired first-party cargo-deny license-file bindings for the current BUSL
  license and all workspace crates.
- Pinned the remaining wildcard local dependencies.
- Corrected third-party notices to reflect that the OSM import feature is
  enabled in the default `bicdb-core` feature set.

## Licensing

This release does not change BicDB's license. Apache-2.0 publication remains a
separate, explicitly gated future decision.
