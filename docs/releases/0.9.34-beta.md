# BicDB 0.9.34-beta

Released: 2026-07-21

BicDB 0.9.34-beta closes the PostgreSQL 18.4 data-type parity program for the
documented, exercised type surface. This is a type-compatibility milestone, not
a claim that every PostgreSQL SQL, extension, optimizer, replication, or
operational feature is implemented.

## Highlights

- Accounts for all 473 PostgreSQL 18.4 `pg_type` oracle rows and supports all
  51 general-purpose type roots, with explicit rationales for four internal-only
  roots.
- Passes all 89 differential fixture groups with zero expected or unapproved
  differences.
- Rejects unknown typed storage, comparison, parameter, result, and composite
  field paths instead of silently falling back to text or OID 25.
- Passes prepared text and binary round trips with psql, node-postgres, psycopg,
  SQLAlchemy, SQLx, JDBC, libpq, and in-process tokio-postgres coverage.
- Completes catalogs, casts, common-type selection, statistics and operator
  classes, ALTER COLUMN TYPE, dump/restore, and database-local user-type/OID
  isolation.
- Passes the workspace, recovery, backup, sync, WASI, Chromium browser, and
  packaging acceptance gates with compiler fan-out capped at 10 jobs.

## Compatibility evidence

The generated [PostgreSQL compatibility report](../../POSTGRES_COMPATIBILITY.md)
and [machine-readable evidence](../../reports/postgresql-18-type-compatibility.json)
are authoritative. PostgreSQL compatibility remains limited to behavior those
checked-in gates exercise; unsupported behavior must fail explicitly.

## macOS arm64 artifacts

The `macOS arm64 release` workflow builds and smoke-tests the CLI, Carrier
Broker, native desktop application, DMG, PKG, and ZIP on a GitHub-hosted Apple
Silicon runner. It publishes checksummed `bicdb-0.9.34-beta-macos-arm64`
workflow artifacts.
