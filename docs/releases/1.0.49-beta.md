# BicDB 1.0.49-beta

Release date: 2026-08-03

## Durable all-voter schema staging

- Adds a bounded, checksummed, restartable coordinator for distributing one
  signed additive schema stage to every frozen metadata voter.
- Freezes the exact cluster, committed topology generation, metadata leader,
  sorted active-voter set, shared live fingerprint, signed target, and limits.
- Advances at most one voter per call and atomically checkpoints each validated
  destination receipt before advancing its durable cursor.
- Retries the same voter safely after a lost response by relying on the
  destination's durable idempotent stage receipt.
- Rejects leadership, topology, voter, cluster, or base-fingerprint drift.
- Connects the coordinator directly to the authenticated cluster TCP transport.
- Revalidates state bounds, checksum, signature, receipt prefix, and symbolic
  link safety whenever an interrupted rollout is opened.

Schema activation remains pending and is never implied by a completed stage
rollout.
