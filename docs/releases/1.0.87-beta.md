# BicDB 1.0.87-beta

## Bounded, resumable orphaned-free-page reclamation

- Adds `PagedStore::reclaim_orphaned_free_pages_step`, a bounded, cursor-
  resumable maintenance pass that reclaims pages an interrupted free-list
  publication left typed `Free` on disk but absent from the intrusive free
  list — reusable space that would otherwise never be allocated again.
- The pass walks the free list once to build a membership set, scans page
  headers in bounded, resumable steps, and relinks any Free-typed page that is
  not a member. It only ever touches pages already typed `Free`, so an
  interruption can leak reusable space but can never lose a live page.
- Relinked Free images go through the buffer pool and are WAL-logged as
  structural records, the pool is flushed so the file matches, and only then
  does the superblock atomically adopt the segment — the same crash-consistent
  ordering vacuum uses for freeing fully-dead pages.
- Hard envelopes per step: page-visit, byte, free-list-visit, adoption-batch,
  and cooperative-duration limits. A free list larger than the visit budget
  defers without mutation; a filled adoption batch stops at an inclusive cursor
  so later orphans are reclaimed by a following step rather than skipped.

## Explicit boundary

This is page cleanup, not the whole-file/extent rewrite the Phase 3 roadmap
still names: it returns orphaned free pages to the allocator but does not
relocate live pages or defragment the file. A durable resumable whole-file
rewrite, CLI wiring, and durable-supervisor scheduling for this pass remain
follow-up work.
