# BicDB 1.0.50-beta

Release date: 2026-08-03

## Crash-resumable local schema activation

- Adds checksummed node-local activation checkpoints for signed additive schema
  stages on non-empty databases.
- Applies at most one collection, structural catalog record, or index per step
  while bounding the number of signed bundle items inspected.
- Revalidates signatures, limits, cursor phases, and the exact additive live
  prefix on every step and reopen.
- Safely reconciles a crash after a schema object committed but before its
  activation cursor advanced.
- Preserves existing rows and delegates index visibility to the existing
  shadow-generation atomic publication path.
- Allows abort only before any schema object has been applied, including
  fingerprint-neutral internal catalog collections.
- Refuses to discard a stage with an activation checkpoint or changed live
  prefix.
- Validates signed collection security policy and vector-dimension metadata
  before staging or activation.

Cluster-wide activation fencing, RPC, receipts, and topology publication remain
pending.
