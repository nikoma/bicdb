# BicDB 1.0.42-beta

Release date: 2026-08-03

## Governed compaction and index construction

- Adds compaction-lane admission before compaction checkpoint creation,
  collection rewrites, and log checkpointing.
- Adds index-build admission around online creation and each public resumable
  FTS prepare, batch, tokenization-finish, merge, and publication boundary.
- Rejects under-declared index memory when it is below the configured FTS
  builder working-set ceiling.
- Releases every permit on success and error without advancing resource usage
  counters or leaving an in-flight reservation behind.
- Proves saturation leaves compaction checkpoints and FTS workspaces absent.
