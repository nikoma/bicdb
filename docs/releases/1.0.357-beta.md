# BicDB 1.0.357-beta

This release extracts product and industry-specific implementations from the
canonical database repository.

- Moves Carrier Broker, the HL7 provider, WalkNorth desktop packaging, ERP/EHR
  fixtures and vertical reports into the sibling integration workspace.
- Moves healthcare projections and healthcare/FHIR program built-ins behind
  public BicDB event, graph and application-host contracts.
- Replaces public PHI-specific APIs with industry-neutral protected-data APIs,
  retaining legacy environment and storage aliases for existing databases.
- Generalizes signed ERP module metadata into application-module contracts,
  retaining one-way deserialization aliases for existing signed packages.
- Makes CLI graph operations accept a serialized `GraphProjection` rather than
  selecting a built-in clinical graph.
- Removes vertical benchmark and CLI commands from the database distribution.

The database remains complete and production-capable without the integrations
repository. The repository license is unchanged.
