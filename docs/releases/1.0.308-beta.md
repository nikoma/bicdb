# BicDB 1.0.308-beta

Release date: 2026-08-24

## Self-reconciling large full-text builds

- Adds a durable, versioned FTS lifecycle report derived from BicDB's own
  checkpoint and currently published generation. External marker files are no
  longer needed to decide whether a build is active, serving, resumable,
  awaiting producer input, published, or blocked.
- Adds idempotent reconciliation for interrupted row-backed builds,
  finalization, and publication. Repeated calls safely converge or report that
  the same generation is already published.
- Preserves the last published generation throughout replacement builds and
  recovers the narrow crash window after the atomic generation swap without
  rebuilding or changing the serving generation identity.
- Discovers checkpoint-only workspaces so catalog damage is surfaced as a
  machine-readable blocked state instead of disappearing from fleet status.
- Adds a resource-governed reconciliation API for production supervisors.
- Adds `bicdb index fts-status`, `bicdb index fts-reconcile`, and the read-only
  SQL function `bicdb_fts_build_status(index_name)`.
- Pins reopen, repeat-reconcile, direct-ingest, and post-publication crash
  behavior in integration tests.

The full contract and supervisor loop are documented in
[`../full-text-build-lifecycle.md`](../full-text-build-lifecycle.md).
