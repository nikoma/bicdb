# BicDB 1.0.438-beta

This is the first downloadable CLI beta for the public source repository.
The release provides a Linux x86-64 archive and SHA-256 checksum file, alongside
GitHub's source archives. The source version is unchanged from the initial
public snapshot; this release makes that version installable without compiling.

## Install and try it

Download `bicdb-1.0.438-beta-linux-x86_64.tar.gz` and `SHA256SUMS` from the
[GitHub release](https://github.com/nikoma/bicdb/releases/tag/v1.0.438-beta).
Verify with `sha256sum -c SHA256SUMS`, extract the archive, and follow the
[README quickstart](../../README.md#five-minute-quickstart).

The binary is validated on **Ubuntu 24.04, x86-64**, with glibc 2.39 and OpenSSL
3 shared libraries. Ubuntu packages `libssl3t64` and `libgcc-s1` provide runtime
dependencies if absent. This artifact does not promise compatibility with older
glibc, Alpine/musl, ARM, Windows, or macOS. Other environments can build the
source using Rust 1.96.0 and the native prerequisites in the README.

No Docker image or other platform binary is published in this release.

## Contents

- `bicdb`: optimized CLI, native SQL, pgwire server, RESP cache, and supported
  engine/application commands; optional benchmark commands are excluded.
- `BUILD.json`: source revision, target, version, and executable checksum.
- BicDB license, scope, attribution, and component notices.
- `third-party/`: dependency license texts, provenance for supplemental notices,
  and checksum-verified registry source archives, including build dependencies.

The build uses `cargo build --locked --release -p bicdb-cli` with the pinned
Rust toolchain. Debug information is stripped only from the packaged copy.
The archive installs no service and changes no existing database automatically.

## Validation and scope

The release smoke test exercises the exact README SQL/full-text example, reads
persisted data in a new process, queries the same directory through `psql`, and
reopens it after server shutdown. Packaging verifies registry archives against
`Cargo.lock`, includes license material, and checks the reported CLI version.

The [compatibility report](../../POSTGRES_COMPATIBILITY.md) identifies this source
version separately from the historical version that produced its retained
PostgreSQL 18.4 matrix. Publishing this beta does not claim a fresh run of that
matrix or a new full engine-suite run. BicDB remains beta; test your application,
authentication configuration, and recovery procedures before deployment.
