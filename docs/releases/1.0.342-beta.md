# BicDB 1.0.342-beta

This release restores PostgreSQL 18.4-compatible `initcap(text)` evaluation in
ordinary row projections.

## PostgreSQL-compatible SQL behavior

- Evaluate `initcap(text)` and `pg_catalog.initcap(text)` for both constant and
  table-backed expressions.
- Preserve PostgreSQL null propagation and alphanumeric word-boundary behavior.
- Apply Unicode upper- and lower-case mappings while constructing the result.

## Validation

- Compared representative ASCII, punctuation, digit, underscore, Unicode, and
  null inputs directly with PostgreSQL 18.4.
- Added a regression for the WalkNorth EHR calendar projection that composes
  `INITCAP(REPLACE(column, ...))`, `NULLIF`, `COALESCE`, and concatenation over
  a table row.
