# BicDB 1.0.7-beta

Release date: 2026-08-03

## Shared SQL spill governance

- Adds `query_server_temp_space_bytes` and
  `BICDB_QUERY_SERVER_TEMP_SPACE_BYTES`, with a 64 GiB default aggregate
  ceiling for concurrent external sorts sharing one canonical spill root.
- Accounts reservations atomically and returns SQLSTATE `53100` before the
  aggregate ceiling can be exceeded. If live callers specify different
  limits, the strictest value wins and cannot be raised by another query.
- Reclaims reservations only as merge inputs are actually removed, and fails
  closed if an input run cannot be deleted.
- Uses `<database>/tmp/sql-spill` by default so cleanup authority is scoped to
  one database. `BICDB_SPILL_DIR` remains available as a dedicated override.
- Scavenges abandoned `bicdb-sort-*` workspaces and legacy run files on first
  use after restart while preserving unrelated files and never following a
  symlink target.
- Keeps the 1.0.6-beta per-operator memory, temp-space, checksum, fan-in, and
  fail-closed fallback guarantees.
