# BicDB 1.0.311-beta

## Single-term BM25 route correction

- Keeps single-term BM25 queries on the existing exact block-max seeking
  kernel, whose per-block exact BM25 bound retires broad posting ranges.
- Uses impact-ordered BM25 only for conjunctive multi-term queries, where its
  score-first traversal is beneficial.

This fixes the regression in 1.0.309-beta where broad one-term queries entered
the impact traversal first and spent their deadline walking a term-frequency
tie plateau instead of using the purpose-built single-term kernel.
