# BicDB 1.0.41-beta

Release date: 2026-08-03

## Governed backup and restore work

- Adds backup/restore lane admission to bounded cluster-backup fencing,
  artifact-capture, certificate-publication, and fence-release entrypoints.
- Guarantees that resource saturation is detected before a backup callback can
  issue remote work or append false journal progress.
- Scopes each permit to one existing bounded journal batch and releases it on
  success, provider failure, and journal failure.
- Adds a governed whole-certificate restore-admission compatibility entrypoint
  that admits before archive hashing, database opening, integrity scans, or
  range-catalog verification.
- Preserves the original APIs for compatibility while making the PB-scale host
  path explicitly resource-governed.
