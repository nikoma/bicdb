# 1.0.525: crates.io packages describe themselves as BicDB

The first crates.io upload of 1.0.524 stopped after eight packages
(`bicdb-lua`, `bicdb-page`, `bicdb-core`, `bicdb-analytics`,
`bicdb-extension`, `bicdb-script`, `bicdb-sql`, `bicdb-workflow`). Their
crates.io pages had no README, and their descriptions did not say they belong
to BicDB. A published version cannot be changed, so all 27 packages are
published again as 1.0.525. The `bicdb` crate itself was never published as
1.0.524.

## Changed

- **README for every package.** Each of the 26 `bicdb-*` packages ships its
  own README. It says what that package does and that it is part of BicDB,
  then gives the full BicDB overview and `cargo install bicdb`. `bicdb-core`
  explains how to embed the engine in a Rust program.
- **Descriptions** of the internal packages now end with: "Part of BicDB, one
  database for SQL (PostgreSQL protocol), a Redis-compatible cache, search
  and vectors; install `bicdb`".
- **Keywords.** Every internal package has the keyword `bicdb`, so a
  crates.io search for it lists the whole set. `bicdb-core` also has
  `database`, `sql`, `embedded` and `search`.

No code, dependency or behaviour change; the crate sources are those of
1.0.524, which were built from their packaged tarballs and installed with
`cargo install --locked` before upload.
