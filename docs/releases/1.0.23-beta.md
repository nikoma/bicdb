# BicDB 1.0.23-beta

Release date: 2026-08-03

## Immutable page extents for tiered storage

- Adds versioned warm/cold page-extent descriptors that bind exact page ranges,
  checkpoint LSNs, sizes, content hashes, and provider object identities.
- Verifies every source page before sealing and streams upload/download through
  explicit bounded buffers, independent of database size.
- Adds a content-addressed local provider with canonical keys, no-follow file
  opens, atomic no-overwrite publication, durability syncing, and idempotent
  duplicate uploads.
- Cleans up operation-owned incomplete uploads on short reads, I/O errors,
  overlong streams, hash changes, and publication failures without touching a
  prior valid object.
- Rejects malformed or forged serialized object keys without panics and refuses
  non-regular objects and unsafe deletion targets.
