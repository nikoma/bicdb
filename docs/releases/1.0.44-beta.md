# BicDB 1.0.44-beta

Release date: 2026-08-03

## Restartable incremental compaction

- Adds a checksummed, atomically persisted offline compaction state machine.
- Rewrites at most one canonical collection per resource-admitted tick, then
  advances log checkpointing and catalog/snapshot publication independently.
- Reopens at the exact completed-collection cursor rather than restarting the
  full database rewrite.
- Pins the database commit sequence and fails before log truncation when a
  write occurs between ticks.
- Makes every destructive finalization phase idempotent across a lost local
  checkpoint.
- Safely discards only validated coordinator state; completed collection files
  and all committed rows remain usable and a new run starts from current state.
