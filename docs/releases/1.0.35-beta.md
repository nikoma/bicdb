# BicDB 1.0.35-beta

Release date: 2026-08-03

## Quorum-certified bounded repair apply

- Adds cluster data protocol v15 and a host-brokered destination repair RPC.
- Requires a valid divergent digest report, a quorum-certified source member,
  a current divergent destination voter, an exact range epoch and majority,
  and the destination's matching completed node-owned digest root.
- Rechecks the durable write fence and resolved prefix around the transaction
  using destination-node time.
- Restricts every canonical, unique upsert or delete to one reported divergent
  token bucket under explicit record, mutation, byte, state, and retained-
  session limits.
- Applies each batch atomically through BicDB's normal WAL, index, constraint,
  and transaction machinery with only the physical-repair admission bypass.
- Atomically checkpoints a checksummed contiguous batch chain and safely
  recovers the row-commit/checkpoint crash window through idempotent replay.
- Keeps completed input separate from health: no fence release or healthy
  result is possible until a fresh digest matches the certified source root.
