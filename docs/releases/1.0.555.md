# 1.0.555: the regression harness uses real server-side COPY

## Changed

- **The PostgreSQL regression harness runs server-side COPY for real.** The
  test server is started with the regression source and run directories as
  allowed COPY directories and with COPY PROGRAM enabled, so the suite's
  `COPY ... FROM '<file>'` statements exercise the server path instead of
  being rewritten to client-side `\copy`. The rewrite remains available with
  `--adapt`. The harness also runs with `max_prepared_transactions = 2`, as
  the upstream regression driver does, so `prepared_xacts` runs its enabled
  variant.
