# BicDB 1.0.361-beta

This release completes the Apache-2.0 readiness audit without changing BicDB's
license.

- Records chain-of-title, contributor, AI-assistance, dependency, fixture,
  generated-code, vendored-asset, trademark, namespace, CLA/DCO, SPDX, NOTICE,
  and release-workflow gates.
- Classifies repository separation as ready while explicitly blocking an
  Apache release until legal and provenance evidence is complete.
- Removes stale licensing policy for the extracted Carrier Broker package and
  corrects the active BUSL release-line wording and npm mirrors.
- Makes the sample gRPC protobuf package and trace metadata product-neutral.
- Extends the architecture gate to protobuf, WIT and serialized public example
  contracts.
- Repairs licensing validation for the intentionally absent public
  `products/` directory.

BicDB remains under its existing BUSL-1.1 terms. Relicensing is a separate,
future approval event.
