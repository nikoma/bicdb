# BicDB 0.9.36-beta

Planned release: 2026-07-22

BicDB 0.9.36-beta adds an opt-in WalkNorth Auth development companion to the
native Mac application and DMG.

## Highlights

- Bundles the Carrier-generated Rust auth executable and its exact generated
  migration alongside BicDB and Carrier Broker. Release packaging pins
  WalkNorth Auth 1.0.1 by exact commit.
- Adds a native Auth Server panel for database, OIDC, browser-origin, and
  WebAuthn settings.
- Adds “Fill Local Development Defaults” as a field-only preset. There is no
  persisted local-development acceptance flag and validation is never skipped.
- Enforces loopback binding and loopback database/origin settings in both the
  app and a separate native launcher.
- Generates unique RS256, protected-context, magic-link, client-secret, MFA,
  social-provider, blob-signing, and bootstrap secrets per Mac. Secrets use
  owner-only files and never enter the launchd plist.
- Applies the signed generated migration transactionally, records its checksum,
  rejects dirty or mismatched migration history, and preserves Carrier's
  runtime-role and schema-readiness checks.
- Pins the Carrier generator revision in release CI, builds the Rust target,
  runs its security regression suite, and records the auth binary and migration
  hashes in the signed app bundle.
- Fixes PostgreSQL 18 session-identity resolution and ordered `string_agg`
  behavior used by Carrier's mandatory runtime-role checks; those checks remain
  enabled.

## Scope

Rust is the preferred implementation language for the bundled,
security-sensitive companion, and the former critical generated-target
advisory is remediated. This package remains local-development-only rather than
claiming production replacement status until the Rust target reaches the same
tested feature and operational parity as the source-owned Node service.
