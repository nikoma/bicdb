The original Registered receiver retains its actual A, native/profile-2 final
image and catalogue materialization. It never becomes a legacy local image,
local OLD quorum or initial writer. Original host custody precedes fallible
continuation. Native DECISION attempts retain the complete body, candidate
bytes and actual native xid before first put. Successful native commit, actual
abort and unknown effects remain distinct. A post-write metadata refusal can
reconcile only the same known committed record under a fresh genuine proof;
visible bytes alone do not resolve an unknown native outcome.

The local metadata version is not a distributed lease. Fresh authenticated
Role/OWN quorum evidence, native epoch/dual-quorum promises and ordinary
request-specific Strong barriers remain necessary. The actual MStore
invalidates its version before an authority mutation. Mutation completion may
publish a ready version only after actual successful persistence. A running
failed/dirty version stays poisoned through harmless persistence, nested
failure or no-op heartbeat. Positive metadata read/HostMQ producers refuse it.
Only original actual-open initialization can complete its own initialization.

Phase points are captured from the original attached native metadata Store
outside service/engine locks. Protected native initialization version 1 refuses
a missing point. Explicit legacy initialization version 0 does not acquire a
native-metadata qualification. Identity-only DB/base/catalogue observations
remain separate from current MStore authority.

DECISION, preparation, native bridge, Open, release and first DATA policy use
actual point checks and final short local version gates. Physical readbacks
and original hook/admission/native journal/A scopes precede and remain lexical
through their relevant gate. Final cache/hook/arm operations are concrete memory
operations; native reads, hashes, serialization, callbacks, filesystem work and
retired owner destruction happen outside that gate. The first policy's sealed
candidate borrows its actual native readback/journal and original registration;
a caller cannot substitute a Weak<State> or decoded policy. Its service/cache
and routing slots are borrowed before publication. Same-State survivor Serving
policy remains selected-range scoped. The new target has exactly one local
voter range; other populated range descriptors must remain unchanged and their
native state must remain unknown at this target.
