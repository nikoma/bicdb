# BicDB 1.0.62-beta

Release date: 2026-08-04

## Run-bound raw certification artifacts

- Advances immutable cluster certification plan, collector state, and report
  formats to version 7.
- Defines a versioned, newline-delimited raw-artifact envelope with a hard
  64 KiB header limit.
- Binds every raw file to the exact run ID, profile, BicDB version, source
  revision and dirty state, artifact kind, observation interval, and all five
  planned producer nodes.
- Declares payload format, nonzero record count, payload byte count, and
  payload SHA-256 in the authenticated header.
- Verifies payload and whole-file size and hashes in one streaming pass using a
  fixed 1 MiB buffer, regardless of artifact size.
- Enforces the envelope during both durable artifact registration and
  independent offline bundle verification.
- Rejects opaque legacy files, oversized or unterminated headers, unknown
  header fields, cross-run or wrong-kind evidence, partial/duplicate producer
  sets, out-of-window observations, zero payloads, truncation, extension, and
  payload corruption.
- Rejects inner-envelope substitution even when an attacker recomputes the
  outer artifact entry, report, and publication-manifest hashes.
- Rejects symlinked raw artifacts at registration and verification.
- Exports the raw-artifact header and payload-format contract through the core
  public API for first-party collectors.
- Adds adversarial coverage for opaque and unbounded headers, self-consistent
  cross-run substitution, and payload changes hidden behind recomputed outer
  publication hashes.

This release freezes the raw-artifact transport envelope. It does not claim
that production hardware runs or their artifacts have already been published.
