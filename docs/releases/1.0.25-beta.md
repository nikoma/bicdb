# BicDB 1.0.25-beta

Release date: 2026-08-03

## Bounded tiered extent hydration cache

- Adds a disposable local extent cache with explicit hard byte, entry,
  concurrency, admission-wait, and crash-cleanup limits.
- Coalesces concurrent misses for one content address and reserves capacity
  before provider I/O, preventing a hydration storm from overcommitting disk.
- Streams downloads into unique staging files, verifies object hashes and every
  BicDB page, and atomically publishes the same inode without a second
  extent-sized disk copy.
- Pins active readers, evicts only least-recently-used unpinned entries, refuses
  admission when the cache cannot stay within its bounds, and safely discovers
  or trims cache contents after restart.
- Detects corrupt cached bytes, removes them after the last reader releases the
  object, and rehydrates from the authoritative provider on the next access.
- Exposes resident/reserved bytes, entries, active hydrations, hits, misses,
  evictions, and corruption counters.
