# BicDB 1.0.329-beta

This release adds an explicit read-serving startup mode for immutable,
generation-backed full-text databases.

## Corpus-size-independent FTS open

- Add `DbConfig::with_paged_rowid_registry(false)` for handles that use
  generation-backed FTS and hydrate results directly by primary key.
- Skip the in-memory primary-key/row-id registry build on those handles. The
  registry previously walked every document key during open; WalkNorth's
  41-million-document immutable base was still unavailable after six minutes
  even though WAL recovery had completed in five seconds.
- Keep the registry enabled by default. General SQL and row-id-addressed
  secondary-index hydration therefore retain their existing behavior.

This option is intentionally scoped: callers that disable the registry must
not use that handle for row-id-addressed secondary-index hydration. Direct
primary-key reads and FTS results that carry primary keys remain supported.

## Validation

- Added a paged FTS regression with both full-text and unique B-tree indexes,
  2,000 records, a registry-free reopen, a full-text lookup, and batch
  primary-key hydration.
- The default-on registry behavior remains covered by the existing paged FTS,
  B-tree, SQL, and storage suites.
