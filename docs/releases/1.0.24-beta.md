# BicDB 1.0.24-beta

Release date: 2026-08-03

## Atomic tiered page generations

- Adds checksummed generation manifests with contiguous page coverage, exact
  checkpoint binding, database identity, monotonic generation history, and an
  authenticated previous-manifest chain.
- Publishes append-only manifests and activation markers atomically under an OS
  ownership lock; a crash before activation leaves the previous generation
  usable and a retry is idempotent.
- Uses compare-and-swap active hashes to reject stale publishers, gaps,
  conflicting generations, identity changes, page-size changes, and checkpoint
  or creation-time regression.
- Fully verifies hashes and every page's ID, checksum, generation trailer, and
  type for new or changed extents before activation while reusing verification
  inherited from the previous generation for unchanged objects.
- Bounds manifest bytes, extent count, activation history, and crash-staging
  cleanup; malformed names, symlinks, non-regular files, tampering, and cleanup
  budget exhaustion fail closed.
