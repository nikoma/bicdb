# BicDB 1.0.33-beta

Release date: 2026-08-03

## Durable quorum digest runs

- Adds a checksummed, atomically checkpointed multi-voter digest run created
  only from an exact `RangeBackupFenceQuorum`.
- Advances at most one replica by one bounded step and enforces hard replica,
  step, digest-memory, and run-state limits.
- Fetches node-owned state before every compare-and-advance, recovering the
  crash window where a remote checkpoint succeeded but its response was lost.
- Canonically groups completed roots and reports bounded divergent buckets.
- Distinguishes healthy, divergent-with-a-quorum-source, and divergent-without-
  authority; the latter cannot feed automatic repair.
- Rejects duplicated/non-voter evidence, regressed progress, unsafe checkpoint
  files, changed limits, corrupted state, and expired fences.
