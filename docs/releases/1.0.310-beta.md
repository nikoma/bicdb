# BicDB 1.0.310-beta

## Bounded-memory sealed FTS impact reads

- Streams packed impact sidecars one block at a time instead of materializing
  the complete sidecar for a term before score-first pruning begins.
- Streams the k-way merge across progressive sub-segments as well, retaining
  only one head block per segment.
- Adds a regression test proving that the first block remains readable when a
  later block becomes unavailable after the cursor is created.

This fixes multi-gigabyte transient allocations and query timeouts for common
terms in large sealed indexes. Query ranking and on-disk format are unchanged.
