# BicDB 1.0.36-beta

Release date: 2026-08-03

## Crash-resumable external anti-entropy merge

- Adds a disk-backed repair coordinator that stages certified-source and
  divergent-destination bucket streams as immutable bounded files.
- Externally merges both streams with fixed memory and work per advance,
  producing exact upserts and source-proven deletes.
- Places source frames, destination frames, mutation batches, steps, and state
  under explicit file, byte, work, and count limits.
- Holds a per-run OS lock across artifact creation, remote apply, and atomic
  local checkpoint replacement so concurrent coordinators fail closed.
- Durably writes frames and immutable batches before durable state or remote
  mutation, while adopting orphan frames and replaying uncertain applies after
  crashes without restarting the bucket.
- Keeps successful application in `awaiting_verification`; it neither releases
  the write fence nor declares health before a fresh digest matches the
  certified source root.
