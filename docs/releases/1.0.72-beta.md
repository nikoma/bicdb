# BicDB 1.0.72-beta

This release makes server-paged B+ tree structural verification bounded,
restartable, and safe against cyclic or malformed node links.

## Bounded structural verification

- Adds a strict serialized cursor and finite per-step ceilings for entries,
  leaf pages, logical page bytes, key bytes, cooperative duration, cursor-key
  bytes, and tree height.
- Holds the structure read lock only for one bounded step and resumes from an
  exact leaf/key boundary after process restart.
- Returns exact stop reasons, progress counters, first-step height, classified
  structural faults, completion, and the next cursor.
- Bounds both per-step cycle memory and complete-sweep traversal using the
  observed file page count.

## Fail-closed page validation

- Safely validates page kind and identity, directory/free-space bounds, entry
  ranges and overlap, strict node ordering, and interior child width and
  presence before using normal node accessors.
- Detects root-descent cycles, leaf-sibling cycles, height exhaustion,
  traversal exhaustion, and ordering violations across leaf boundaries.
- Preserves checksum, torn-page, short-read, and physical I/O errors instead of
  replacing them with a generic corruption sentinel.

## Public integration

- `PagedStore`, `PagedRecords`, and `BicDb` expose the same bounded step API.
- Embedded-memory mode rejects the paged-only operation explicitly.
- Strict cursor, limit, fault, and report contracts reject unknown fields and
  invalid restart state.

## Verification

Tests cover exact multi-step key accounting, restart after database reopen,
large runs of empty leaves, leaf and root cycles, malformed cursor state,
strict serialization, resource ceilings, public API forwarding, and
embedded-mode rejection.
