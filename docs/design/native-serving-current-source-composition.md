Resolution retains the original per-poll child deadline and both real

## Required acceptance remains open

Static formatting, version identity, dependency direction, source preservation
and documentation links are source checks only. The original full Serving
SDK/new-APP/full-Strong control must still run, as must each new component
definition and required broad suites on the final versioned head.

The new drain control cancels after Closed life ends but before the real drain
API's first cancellation check and socket shutdown. It verifies that exact
continuation boundary; it does not test partially completed socket shutdown.
The component requires the same Installed/native evidence and an incomplete,
APP-closed Joined result. It stops before the full SDK tail.

Actual new-epoch recovery, late publication refusal, multi-range fairness,
topology/admission lock contention, recovery after fault removal and independent
range progress need their own genuine controls. Automatic placement/controller
progress, final metadata, eight-phase custody cleanup, repeated movement and
cold reconstruction remain incomplete. Cold bootstrap source association and
the native final acknowledged-prefix producer remain separate open work.

No physical four-to-five convergence, zero-loss qualification, measured RPO/RTO,
post-convergence capacity gain or transparent multi-range SQL is established.
The complete external attempt/ACK/uncertainty/retry ledger and all original
physical acceptance gates still apply to a future isolated experiment.
