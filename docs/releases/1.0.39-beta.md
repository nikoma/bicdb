# BicDB 1.0.39-beta

Release date: 2026-08-03

## Hierarchical node resource governance

- Adds a shared node governor for explicit resident-memory, in-flight-I/O, CPU,
  concurrency, and I/O-rate demands.
- Defines seven fixed-cardinality lanes for consensus, foreground reads/writes,
  anti-entropy, backup/restore, compaction, and index construction.
- Preserves configured consensus/write headroom by capping every noncritical
  lane below node totals and separately limiting combined background work.
- Enforces per-lane hard capacity, active-operation, and token-bucket rate
  bounds before work allocates resources.
- Returns RAII permits that release in-flight reservations deterministically on
  success, early error, and unwinding.
- Exposes bounded snapshots for node, noncritical, background, and lane usage,
  admissions, rejections, and rate tokens.
