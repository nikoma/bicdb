# BicDB 1.0.11-beta

Release date: 2026-08-03

## Quorum-certified follower apply

- Separates provisional decision replication from quorum certification and row
  application. Followers cannot expose a row merely because one commit RPC
  reached a minority partition.
- Requires a majority of durable provisional decisions before the leader
  writes its quorum certificate. Only then can followers apply the command.
- Aborts provisional decisions when decision quorum fails; those entries never
  enter startup replay and remain safe to resolve after a crash.
- Replays only `quorum_committed` decisions. Certification is durable before
  follower row apply, and the applied checkpoint remains durable before its
  acknowledgement.
- Upgrades the range-write protocol and on-disk log to v2. V1 committed entries
  are atomically migrated to quorum-certified state to retain their published
  recovery behavior.
- Extends authenticated cluster data RPC to protocol v8 with separate certify
  and apply operations, including idempotent repeated apply coverage.
