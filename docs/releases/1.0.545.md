# 1.0.545: function error CONTEXT, max_stack_depth, erf/gamma and catalog lookup functions

Part of the PostgreSQL SQL-parity work, checked against stock PostgreSQL 18.4
with `fixtures/postgres-compat/pgsql-parity/j2.cases`.

## Added

- **CONTEXT lines for errors and notices raised in functions**: PL/pgSQL
  functions, procedures, trigger functions and DO blocks report `PL/pgSQL
  function f(integer) line N at ...`, with `SQL statement "..."` for an error in
  an embedded statement and one line per routine on the call chain; SQL-language
  functions add `SQL function "f" statement N`. Such errors carry no position in
  the client's query, as in PostgreSQL.
- **`max_stack_depth`**: SET (superusers only, 100kB up to the platform limit,
  PostgreSQL's unit and range errors), SHOW and RESET; the "stack depth limit
  exceeded" HINT reports the session's value.
- Functions: `erf`, `erfc`, `gamma`, `lgamma`, `casefold`, numeric `gcd`/`lcm`,
  `range_adjacent`, `pg_trigger_depth`, `pg_current_xact_id[_if_assigned]`,
  `to_regrole`, `to_regcollation`, `to_regoper`, `to_regoperator`,
  `to_regtypemod`.
