# BicDB 1.0.4-beta

Release date: 2026-08-02

## Live embedded LLM response streaming

- Adds signed Carrier `stream_response` LLM authority, distinct from the
  existing broker-backed `.stream()` event surface.
- Adds provider-native OpenAI SSE streaming with `stream: true`, usage chunks,
  fragmented-event decoding, exact `data:` envelopes, and terminal `[DONE]`.
- Adds scoped live HTTP response capture. Application work runs on a bounded
  blocking worker while the Axum response consumes a bounded channel, so the
  first provider event reaches the client before inference completes.
- Applies response, chunk, deadline, model, token, tool, and signed-authority
  checks. A dropped HTTP client closes the channel and cancels the upstream
  read through provider backpressure.
- Retains buffered stream collection for non-network invocation and test
  paths, while network SSE routes use the live channel path.

Carrier Enterprise 2.3.57 is the first compiler release that emits this
contract and requires BicDB 1.0.4-beta for embedded live LLM routes.
