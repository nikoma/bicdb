# BicDB 1.0.358-beta

This release completes the first physical commercial control-plane extraction.

- Removes BicDB's built-in automatic placement policy from the public engine.
- Makes the public distribution controller runtime manual-convergence by
  default and requires an explicit `ClusterPlacementPlanner` for automatic
  placement or retry policy.
- Adds `ManualDistributionHostService`, preserving a usable community
  replication/data plane and explicit relocation workflow.
- Exposes `PgWireHostContext::start_distribution_controller` so third-party
  controllers can activate public distribution mechanisms without patching
  BicDB.
- Establishes the private sibling `bicdb-platform` workspace with a real
  automatic fleet-controller implementation consuming only public BicDB APIs.

No database security, correctness, backup, recovery, replication, Cell or data
access capability moved out of public BicDB. The repository license is
unchanged.
