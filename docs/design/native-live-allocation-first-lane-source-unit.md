## Explicit open/source-blocking transitions

**RegistryAfterAllocation is not implemented.** A later registry-v1 write cannot preserve the effective epoch2 while validating against original epoch1; the latest allocation proof is currently required. The next independent child needs a distinct typed v2 RegistryAfterAllocation purpose, exact previous-step registry-only succession and full protected native ancestry proving the actual preceding allocation. It must not infer old Unknown IO success, grant a new epoch or replace the original registration. This first lane is not repeatable add-node delivery.

Likewise a later changed-voter/leader or already joint-serving cohort is not accepted by normalizing original policy facts. It needs its actual changed-voter image/Serving transition proof. Existing jobs, replica debts and uncertain native audit state remain retained rather than reset; unresolved old-epoch history across allocation is still a separate necessary producer. The shared whole-policy lane can defer other policy updates while such an original obligation exists. No liveness guarantee under those cuts is claimed.

The unchanged limits are 64 shared immutable registry/allocation entries and 256 KiB per encoded audit/facts representation. Metadata registry entries consume that same history. Consequently this source unit does not establish room for a full 64-relocation campaign after prior registry writes, nor 64-range convergence. A derived bounded history/accounting design and actual large/many-range controls remain necessary; neither arbitrary cap increases nor workload shrinkage is used here. Encoded bounds are not a resident-heap hard cap: caches, retained predecessor facts, candidate/audit objects and serialization can coexist.

Current-artifact FORMAT feature-set denial is tested only by a source definition using the actual validator with the old feature omitted. No old binary was executed, and no mixed-artifact, cross-process, crash/power-loss, cold-restart, automatic-controller, permanent-member-loss or final cleanup/GC qualification is claimed.
