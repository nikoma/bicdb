# BicDB 1.0.8-beta

Release date: 2026-08-03

## Cancellation-safe paged queries

- Adds cancellation-aware server-paged batch scans, resumed scans, and exact
  live-row counts. Cancellation and deadlines are checked before each
  page-backed record is decoded and before a batch reaches caller code.
- Guarantees that a canceled scan unwinds its cursor and releases every
  buffer-pool page pin before returning.
- Propagates the SQL invocation token through streamed projection, aggregate,
  grouping, distinct, ordering, and resumable FTS-tokenization scans.
- Makes external-sort run generation and bounded multiway merges observe the
  invocation token. A canceled sort removes its owned workspace and returns
  its process-wide temporary-space reservation.
- Treats cancellation and deadline failures as fail-closed execution errors,
  so best-effort streaming paths cannot hide them by retrying through a
  materializing fallback.
