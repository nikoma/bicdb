# 1.0.558: COPY options are implemented or refused, never ignored

## Fixed

- **COPY accepted options and then ignored them**, so data loaded with
  different semantics than the statement asked for. Every COPY option is now
  parsed in both the legacy and the parenthesized syntax, validated with the
  same messages and SQLSTATEs as PostgreSQL 18, and either implemented or
  refused with 0A000 before copy mode starts.

## Added

- Text format: DELIMITER and NULL, with the full backslash escape set in both
  directions.
- CSV format: DELIMITER, NULL, QUOTE, ESCAPE, FORCE_QUOTE, FORCE_NOT_NULL and
  FORCE_NULL.
- HEADER and HEADER MATCH with custom delimiters and NULL strings.
- ENCODING: UTF8 and its aliases, SQL_ASCII, and LATIN1 converted both ways
  (22P05 for unmappable characters). Invalid UTF-8 input gives 22021.
- These apply to STDIN/STDOUT, server files and programs alike.
