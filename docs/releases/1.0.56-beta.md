# BicDB 1.0.56-beta

Release date: 2026-08-03

## Quorum-certified learner schema bootstrap

- Fixes a relocation deadlock where an empty learner installed the leader's
  schema but could not advertise it because active schema labels are correctly
  protected from heartbeat mutation.
- Makes the metadata relocation controller publish the exact leader
  fingerprint only after the authenticated destination returns a successful
  schema-install acknowledgement.
- Requires the exact relocation, learner replica ID, range epoch, target node,
  learner role, leader fingerprint, and one-time bootstrap claim.
- Removes the bootstrap claim in the same quorum-staged topology change so it
  cannot authorize a second schema transition.
- Keeps ordinary local and remote heartbeats unable to create, remove, or
  replace quorum-managed active and pending schema labels.
- Makes retry after a lost proposal idempotent: the schema install and
  certification may repeat, while snapshot copying begins only after the
  certified topology is staged.
- Restores the production two-member automatic relocation integration test and
  adds direct regression coverage for single-use authority and forged/missing
  heartbeat labels.
