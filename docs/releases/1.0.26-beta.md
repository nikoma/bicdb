# BicDB 1.0.26-beta

Release date: 2026-08-03

## Reference-safe tiered extent garbage collection

- Adds checksummed, serializable GC checkpoints pinned to the exact active
  manifest, rollback retention window, protected backup-object set, resource
  limits, hash-prefix cursor, and cumulative progress.
- Revalidates the active generation and authenticated retained-manifest chain
  under the publication lock before every destructive step, fencing stale GC
  workers after concurrent activation.
- Scans one of 256 provider hash prefixes at a time with explicit inventory,
  reference, protected-object, delete, and metadata-prune bounds.
- Preserves every active, rollback-retained, and externally protected object;
  orphan deletion and repeated partial-prefix execution are idempotent.
- Prunes old immutable activation/manifest metadata only after the complete
  object sweep, retaining a coherent rollback window.
- Adds bounded, canonical local-provider inventory with symlink, path, empty
  object, and non-regular-file rejection.
