# BicDB 1.0.5-beta

Release date: 2026-08-02

## Invocation-scoped AI streaming

- Extends the 1.0.4-beta live response path with private OpenAI tool-call
  turns. Fragmented function-name and argument deltas are accumulated before
  dispatch, checked against signed tool authority, and omitted from public SSE.
- Keeps one bounded response handle open across the complete provider/tool
  loop. Only the final assistant turn is exposed, followed by exactly one
  `data: [DONE]` terminal event.
- Allows signed Carrier RAG calls to select `stream_response`; native embedding,
  vector retrieval, score filtering, and bounded context construction complete
  before the final LLM response begins streaming.
- Fails closed for undeclared tools, malformed frames, incomplete streams,
  excessive turns, response limits, expired deadlines, and disconnected
  clients.

Carrier Enterprise 2.3.58 is the first compiler release that emits the full
tool-enabled and RAG-enabled streaming contract and requires BicDB
1.0.5-beta for those routes.
