# BicDB 1.0.350-beta

This release fixes an SQL planner divergence found while qualifying the WalkNorth EHR against PostgreSQL 18.4.

## Changes

- Restrict ordinary equality, range, ordering, and dynamic locator plans to B-tree indexes.
- Prevent full-text, JSONB, array, and spatial indexes from being misused as B-tree indexes when they cover the same source field.
- Preserve PostgreSQL results for equality predicates when a Carrier resource has both search and B-tree indexes on its tenant field.
- Add regression coverage for the exact EHR insurance-coverage query shape that exposed the issue.

## Verification

- `cargo fmt --all -- --check`
- `cargo check -p bicdb-sql`
- `cargo test -p bicdb-sql --test sql equality_predicates_do_not_use_full_text_indexes_as_btrees`
- PostgreSQL 18.4 comparison using the same bound tenant/patient predicate and ordering shape.
