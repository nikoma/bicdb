# BicDB 1.0.32-beta

Release date: 2026-08-03

## Authenticated node-owned range digests

- Adds `RangeDigestTransport` to cluster data protocol v13 with membership,
  mTLS identity, destination identity, topology epoch, and schema fencing.
- Keeps follower integrity evidence node-owned: leaders send only an expected
  checkpoint checksum and cannot supply accumulated buckets.
- Atomically persists every bounded scan step in a dedicated retained-session-
  bounded directory and recovers it across service restarts.
- Uses compare-and-advance checksums to reject stale writers while a status
  call recovers safely from uncertain responses without advancing state.
- Refuses symbolic-link checkpoints, malformed checksums, wrong sessions,
  expired fences, and divergent consensus prefixes before changing progress.
