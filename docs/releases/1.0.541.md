# 1.0.541: soft input errors, error positions, temporary tables, VACUUM/ANALYZE, JSON input diagnostics

Part of the PostgreSQL SQL-parity work, checked against stock PostgreSQL 18.4
with `fixtures/postgres-compat/pgsql-parity/f.cases`, `f2.cases` and `j.cases`.

## Added

- **Soft input errors**: `pg_input_is_valid` and `pg_input_error_info` run the
  type's input conversion (enums, domains and type modifiers included).
- **Error positions**: ErrorResponse carries PostgreSQL's position field for
  syntax errors and, in DML, for unknown columns, relations, functions, types
  and invalid literals.
- **CONTEXT lines**: invalid json/jsonb text is diagnosed by a port of
  PostgreSQL's JSON parser, with its DETAIL and `JSON data, line N: ...`
  CONTEXT; multirange literals get PostgreSQL's syntax messages.
- **VACUUM/ANALYZE** accept every PostgreSQL form with PostgreSQL's validation
  and warnings (25001 inside a transaction block); ANALYZE refreshes
  statistics.
- **Functions**: `to_number` with the full number picture, `parse_ident`,
  `float4send`/`float8send`, `hashfloat4`/`hashfloat8`, `ascii`, `unistr`,
  `pg_size_bytes`, `to_hex`/`to_oct`/`to_bin`, `gcd`/`lcm`, `num_nulls`,
  hyperbolic functions, scale helpers, `getdatabaseencoding`, `regexp_count`,
  `regexp_instr`, `regexp_like`, `regexp_substr`.
- psql describe queries (`\d` and friends) work, including
  `pg_table_is_visible` following the search path.

## Changed

- **Temporary tables** live in the connection's `pg_temp_<pid>` schema, shadow
  permanent tables through the search path and are dropped at disconnect,
  `DISCARD TEMP/ALL` and server start. Triggers, self-referencing foreign keys
  and indexes on temporary tables work, and `ON COMMIT DELETE ROWS` / `DROP`
  actions apply.
- **A string cast to an integer type uses the integer input function on every
  path** (`'34.5'::int` is an input error, not 35), including views,
  `INSERT ... SELECT`, domains over text and PL/pgSQL assignments. Numeric
  sources still round.
- A FROM-less SELECT with aggregates, GROUP BY or HAVING reads one implicit row.
- Input error texts for integers, money, bit, tsvector/tsquery and time zones
  match PostgreSQL; numeric field overflow carries its DETAIL; a date beyond
  the supported range no longer aborts the statement.
- View definition text is taken from the statement's source text.
