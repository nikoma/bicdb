# BicDB 1.0.344-beta

This release makes failed application-worker deliveries observable without logging message payloads.

## Changes

- Log the worker name, opaque message ID, attempt count, retry decision, retry delay, and execution error whenever a worker delivery fails.
- Keep application payloads out of worker failure diagnostics so regulated data is not copied into runtime logs.

## Verification

- `cargo fmt --all -- --check`
- `cargo check -p bicdb-app-runtime -p bicdb-cell`
- `cargo test -p bicdb-app-runtime`
