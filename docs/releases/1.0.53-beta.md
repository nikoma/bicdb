# BicDB 1.0.53-beta

Release date: 2026-08-03

## Verified fleet schema finalization

- Adds metadata-leader-authenticated schema finalization in cluster data
  protocol 18 under the exact committed all-voter target fence.
- Requires durable activation completion receipts from every frozen voter
  before fleet cleanup begins.
- Revalidates each node's signed stage, complete activation checkpoint, live
  target digest, activation identity, and state checksum.
- Atomically writes a compact checksummed finalization proof before deleting
  any checkpoint.
- Removes the activation cursor before the signed stage and synchronizes the
  containing directory when durable writes are configured.
- Rejects mismatched cleanup evidence without removing either checkpoint.
- Retries interrupted cleanup or lost responses idempotently against the same
  durable node proof.
- Checkpoints one node-bound finalization receipt at a time and reaches the
  terminal `finalized` phase only with evidence from every voter.
- Reopens 1.0.52 activation-complete rollout checkpoints through serde-defaulted
  finalization fields.

A compatibility window that avoids a whole-cluster write pause remains the
final unfinished coordinated-online-DDL gate.
