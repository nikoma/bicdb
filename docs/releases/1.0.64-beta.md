# BicDB 1.0.64-beta

Release date: 2026-08-04

## Fail-fast production certification checkpoints

- Runs immutable certification gates before `certify-record` rewrites the
  durable collector state.
- Validates each hardware observation for planned identity, complete hardware
  metadata, nonzero CPU/storage/network capacity, and sufficient memory.
- Validates measurement windows, sample counts, logical and physical size,
  bounded RSS, latency regression, quorum/minority behavior, relocation work
  and amplification, recovery timing, final cluster health, FTS scale, and
  exact raw-artifact prerequisites at checkpoint time.
- Validates background saturation across every planned node and fixed resource
  lane, including hard-bound rejection, foreground/quorum work, latency,
  availability, and its exact artifact.
- Validates each destructive failure trial independently without requiring the
  other seven trials to have run yet, including loss ordering, incarnation and
  checkpoint fencing, affected-range repair, fixed-watermark integrity, quorum
  work, identity rejection, and raw failure/checksum evidence.
- Requires measurement evidence before restore or expansion checkpoints and
  rejects obvious provenance, identity, interval, topology, and artifact
  defects immediately. The pair receives the complete cross-dependent restore
  and expansion validation as soon as both observations exist.
- Leaves the prior state untouched when any validation fails, so a corrected
  observation can be retried without losing a known-good checkpoint.
- Updates the production runbook to capture/register raw evidence before
  recording summaries that reference it.
- Adds regression coverage proving invalid hardware, latency measurements,
  failure repair, restore incarnation, and expansion topology are rejected
  before durable state mutation.

This release reduces the chance of completing a long production-scale trial
only to discover that an early evidence checkpoint was structurally invalid.
The physical 1 TB, 5 TB, and 20 TB campaigns remain required.
