# BicDB 1.0.45-beta

Release date: 2026-08-03

## Resumable per-node restore admission

- Adds a single-owner, checksummed restore-admission coordinator with atomic
  state replacement.
- Verifies at most one certificate-bound node per backup/restore-lane tick and
  resumes at the next node after process restart.
- Binds every invocation to the original node, archive path, restored root,
  PITR target, certificate ID, certificate checksum, and common topology.
- Keeps backup passphrases and encryption configuration invocation-only and
  proves they are absent from the durable run state.
- Publishes the final cluster admission report in a separate idempotent phase
  only after exact evidence exists for every certificate artifact node.
- Rejects concurrent coordinators, symlink state/locks, changed limits,
  changed certificates, clock regression, and under-declared archive buffers.
