# BicDB 1.0.30-beta

Release date: 2026-08-03

## Bounded range Merkle digests

- Adds fixed-fanout range content summaries whose memory and comparison cost do
  not grow with row count.
- Binds every root to cluster, token interval, range epoch, and resolved
  consensus-log prefix before two replicas may be compared.
- Applies deterministic record batches under explicit row, byte, record-size,
  bucket-count, and state-file limits.
- Atomically checkpoints checksummed progress and treats an identical uncertain
  batch replay as an idempotent no-op.
- Localizes different data to bounded token buckets while leaving authority
  selection and mutation to the later quorum-certified repair layer.
