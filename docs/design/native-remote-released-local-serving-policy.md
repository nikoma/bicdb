## Actual producer and custody

`NativeMetadataHost::advance_finite_remote_serving_policy` and the existing
fresh Registered learner facade invoke the serialized actual control host.
The method accepts only an original at-most-five-second actor parent. It uses
the SAME retained remote release successor, original participant, native D,
process, phase, manifest and original queue. It refuses a missing known release
return, an in-flight/pending/unknown original RPC, a foreign owner, a cold
learner or an ended process. A history scalar is necessary attribution only;
actual scoped native and metadata proofs remain independently required.

The host retains a distinct local policy owner before any route, queue, native,
socket, or dispatch effect. The original queue then retains only a Weak to that
same owner and refuses subsequent mutations; it never clears Unknown. Policy
helper and outer API returns have separate bounded histories preserving the
original error. A failed later authority check does not undo or forget a known
native install or socket transfer.

## Narrow self authority and effects

`NativeJointLocalServingPolicy` is a distinct metadata role purpose. Only the
actual Active recipient can initiate it for itself as a final voter in the
exact committed CleaningUp/AwaitingActivation session/D/configuration. A
nonleader self is legal only for this purpose. The separate opaque local role
wrapper exposes no generic recovery admission. Generic mutation recovery,
observation and historical-adoption factories explicitly refuse it.

After ALL observations, the same actual self transport obtains an independently
fresh role, OWN and attached current native MStore. Policy admission binds
these to the original released owner, process and physical observation. Existing
local quorum constructors and release/arm sinks are separate and unchanged.

INITIAL survivors use the existing selected native writer-policy sink.
Registered targets use the existing native installer, AssignedClosed owner,
actual original replica drain, unique Assigned-to-Joined custody transfer and
Joined bind. The original replica socket is replica-only, AssignedClosed
admits no APP, and the Joined dispatcher remains closed before publication.
Native policy may precede drain; the actual old socket must stop and drain
before replacement bind. No active-count exception or invented zero-count
permission is added.

The replacement listener receives a Weak readonly route to the SAME actual
host-retained successor before bind. It accepts only protected Open/Released
reads on the same actual runtime/service/phase, with fresh role/OWN/MStore.
It cannot accept mutations, reconstruct an ended owner or clear uncertainty.
The original generic participant lifetime remains strict. A distinct successor
lifetime validates either the original empty hook or the actual terminal writer
registration minted by the real native installer, plus the same original owner.

A listener replacement revokes the earlier ingress point. The known install is
retained first, the old admission is dropped, and a new ALL/self authority phase

role is renewed or reused. If a bind failed after actual installation, a later

This repair does not replay the native installer, publish APP, or use an expired
phase admission. Fresh phase acquisition is still mandatory before new policy
or dispatch effects. Repair-fault runtime coverage is not yet supplied.

The first successful step returns explicitly incomplete after actual policy and

Registered Joined publication keeps the actual protected native/store and

Each ordinary SDK Strong still requires its own fresh barrier.
