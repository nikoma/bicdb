# BicDB 1.0.359-beta

This release makes the open-core repository boundary continuously testable.

- Adds an architecture gate rejecting private or out-of-repository Cargo path
  dependencies from public BicDB.
- Rejects reintroduction of the extracted automatic fleet-controller types.
- Adds a focused community capability validation covering encryption,
  backup/restore/PITR, replication, SQL authorization/RLS, pgwire, Cell
  security, local sync, manual failover and audit/metrics.
- Runs the dependency-direction gate in public GitHub Actions from a clean
  community-only checkout.
- Adds a private-platform validation mode and CI workflow proving that
  `bicdb-platform` compiles against public BicDB APIs without source patches.

The full public workspace build and test matrix remains in place. The
repository license is unchanged.
