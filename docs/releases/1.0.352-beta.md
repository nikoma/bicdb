# BicDB 1.0.352-beta

This release lets PostgreSQL-wire servers keep startup independent of corpus size for scan/direct-primary-key/generation-backed-FTS workloads.

## Changes

- Add `--paged-rowid-registry true|false` to `bicdb serve` and `bicdb serve-pg`.
- Preserve the existing general SQL behavior by defaulting the registry to `true`.
- Allow explicitly compatible workloads to disable the compact primary-key/row-id registry instead of scanning every indexed row during startup.
- Carry the setting through the PostgreSQL-wire server into `DbConfig` and document the workloads for which disabling it is valid.
- Add `bicdb export PATH --collection NAME`, a bounded JSON Lines stream with an exclusive
  `--after-id` resume cursor and explicit row/byte batch limits.
