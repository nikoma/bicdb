# BicDB 1.0.346-beta

This release preserves Carrier/PostgreSQL parity when signed typed SQL returns encrypted model fields.

## Changes

- Apply compiler-signed result projections to `sql.one_as`, `sql.list_as`, and the equivalent typed database helpers.
- Decrypt encrypted model fields before Carrier validates or serializes the signed route response.
- Keep projection authority fail-closed: only projections embedded in the signed package execute, and each decrypt operation still requires its exact host-only field secret binding.
- Cover both single-row and list typed SQL results in the Carrier behavior interpreter.

## Verification

- `cargo fmt --all -- --check`
- `cargo test -p bicdb-app-runtime --lib applies_signed_typed_sql_projection_to_one_and_list_results`
