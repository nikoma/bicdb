# BicDB 1.0.6-beta

Release date: 2026-08-03

## Bounded external SQL sort

- Adds explicit `DbConfig` and environment limits for external-sort work
  memory, temporary disk space, and merge fan-in.
- Makes ORDER BY, GROUP BY, and DISTINCT spill sorted runs by resident bytes
  instead of row count, so wide rows cannot silently defeat the memory bound.
- Performs multi-pass merges without opening an input-sized number of files.
- Frames spill entries with CRC32 checksums and rejects corruption or truncated
  records instead of returning partial query results.
- Gives every sort a uniquely owned temporary workspace and removes it after
  success or failure.
- Returns standard resource-limit SQLSTATEs when a row or temporary merge
  exceeds its configured allowance. These failures cannot fall back to the
  older unbounded materializing path.

Defaults are 64 MiB of work memory, 8 GiB of temporary space, and a 32-run
merge fan-in. See `docs/large-results.md` for configuration details and the
remaining end-to-end query-memory limitations.
