# BicDB 1.0.360-beta

This release completes the product-neutral public API and documentation pass
for the open-core extraction.

- Documents the public controller, Cell, HA, recovery, sync, application,
  provider, and signed-format contracts available to third-party operators.
- Adds canonical `bicdb.current_*` trusted SQL settings while preserving the
  historical settings as read-only compatibility aliases.
- Emits neutral Cell security-profile and hardening-profile names while still
  accepting legacy persisted inputs.
- Moves product UI, browser-platform, packaging, storage-sizing, and private
  fleet-roadmap records to their owning sibling repositories.
- Neutralizes production examples and active database documentation without
  removing generic application/runtime capability.
- Extends the architecture gate to reject new product-named public Rust symbols
  and product language in canonical public documentation.

The repository license is unchanged.
