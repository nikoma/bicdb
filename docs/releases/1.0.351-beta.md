# BicDB 1.0.351-beta

This release prevents a transient transaction-log write failure from permanently wedging every later commit.

## Changes

- Keep contiguous WAL entries in the pending queue until their disk write succeeds.
- Retry retained WAL entries on the next durability attempt instead of leaving an unrecoverable commit-sequence gap.
- Add regression coverage that fails a WAL write, repairs the destination, and proves the original commit is then written durably.

## Verification

- `cargo fmt --all -- --check`
- `cargo test -p bicdb-core --lib failed_write_keeps_commit_pending_for_retry`
- `cargo test -p bicdb-core --test commit_apply_failure`
- `cargo test -p bicdb-core --test wal_acknowledgement_race`
