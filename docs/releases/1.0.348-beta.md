# BicDB 1.0.348-beta

This release closes two SQL-compatibility gaps found while qualifying the WalkNorth EHR against PostgreSQL 18.4.

## Changes

- Accept a scalar Boolean subquery directly as a `WHERE` predicate and apply PostgreSQL's three-valued truth semantics to its result.
- Resolve qualified, unquoted session-keyword column names such as `a.current_user` as row columns while preserving ordinary session function calls.
- Add regression coverage for both EHR query shapes.

## Verification

- `cargo fmt --all -- --check`
- `cargo check -p bicdb-sql`
- `cargo test -p bicdb-sql --test sql split_part_works_in_the_ehr_activity_feed_query_shape`
- `cargo test -p bicdb-sql --test sql boolean_scalar_subquery_is_valid_as_a_where_predicate`
