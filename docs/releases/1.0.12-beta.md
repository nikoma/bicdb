# BicDB 1.0.12-beta

Release date: 2026-08-03

## Quorum-evidenced leader prefix recovery

- Requires every range leader to recover the voter-majority resolved command
  prefix before assigning a new range-log index.
- Computes the recovery watermark from durable progress reported by a reachable
  quorum and rejects writes when quorum evidence is unavailable.
- Fetches contiguous, checksummed applied/aborted suffixes from authenticated
  current voters under the existing command, byte, and batch limits.
- Compares overlapping voter histories and fails closed on divergence instead
  of selecting an arbitrary source.
- Requires a fresh range snapshot when compaction removed the necessary prefix
  or bounded recovery cannot reach the quorum watermark.
- Keeps leader promotion recovery log-only because physical snapshot parity is
  a prerequisite of promotion; ordinary follower repair still applies the
  exact row mutations.
- Extends authenticated cluster data RPC to protocol v9 with bounded repair
  export, including TCP and leadership-transition regression coverage.
