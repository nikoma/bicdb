# BicDB 1.0.61-beta

Release date: 2026-08-04

## Atomic certification publication

- Advances immutable cluster certification plan, collector state, and report
  formats to version 6.
- Adds a versioned `cluster-certification-manifest.json` as the single portable
  publication root for a completed production evidence bundle.
- Binds the exact default plan and report paths, sizes, and SHA-256 values,
  source revision, profile, completion time, every sorted artifact entry,
  artifact count, and total raw bytes.
- Adds a canonical whole-bundle SHA-256 computed over the manifest contract.
- Publishes the manifest atomically only after report verification succeeds and
  the durable collector state becomes immutable.
- Recovers a crash between collector finalization and manifest publication by
  deterministically recreating the missing manifest.
- Refuses to overwrite an existing divergent manifest.
- Makes independent verification fail closed for a missing, empty, malformed,
  symlinked, path-substituted, truncated, reordered, reduced, or
  checksum-mismatched publication.
- Reports the independently verified raw-artifact byte total and manifest
  SHA-256 through the core API and CLI.
- Adds adversarial coverage for external plan substitution, a
  self-consistently reduced manifest, missing publication, resumable
  publication, and divergent-manifest preservation.

This release freezes the portable publication contract. It does not claim that
the production 1 TB, 5 TB, or 20 TB evidence bundles have already been run or
published.
