# BicDB 0.9.35-beta

Planned release: 2026-07-22

BicDB 0.9.35-beta adds the PostgreSQL 18 behavior needed by the current
WalkNorth Auth schema and runtime checks, and hardens the macOS package against
bundling a stale database executable.

## Highlights

- Handles PostgreSQL name/text comparisons such as
  `pg_roles.rolname = current_user` without the former JSONB coercion failure.
- Supports the PL/pgSQL exception, SQLSTATE, pgcrypto digest/HMAC, bit-string,
  transaction ID, and routine-expression behavior exercised by WalkNorth Auth.
- Keeps pgwire statement description side-effect free while allowing
  write-capable PL/pgSQL functions to execute with the required transaction
  mode.
- Passes the complete WalkNorth Auth BicDB verification harness without
  replacing protected-context functions or weakening role/schema checks.
- Makes macOS packaging fail unless the embedded CLI reports exactly
  `bicdb 0.9.35-beta`, records that version in the app metadata, and prefers the
  bundled executable in installed builds.

## Compatibility scope

The PostgreSQL compatibility claim remains evidence-based: BicDB implements the
documented and tested PostgreSQL 18 surface, not every PostgreSQL feature.
