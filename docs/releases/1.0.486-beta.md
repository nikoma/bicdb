# BicDB 1.0.486-beta

This source candidate protects constraint-owned index backings from direct
`DROP INDEX`, including `IF EXISTS` and `CASCADE`. Entire multi-index statements
resolve owners and dependencies before mutation. PostgreSQL dependency
refusals retain SQLSTATE 2BP01; Oracle primary/unique backings retain ORA-02429.

Index removal respects exact quoted identity and namespace, including the
encoded identity stored by explicitly qualified CREATE INDEX. Materialized-view
index descriptors are removed with their Native backing. If restoring an index
during full ROLLBACK fails because another Native transaction remains pending,
the undo entry survives so a later rollback retry actually restores the index.

The initial implementation passed 254 focused checks. An unchanged original
Oracle wire test then exposed the qualified CREATE/DROP lookup regression;
the correction passed eight SQL index/rollback controls, all 50 Oracle wire
tests and all 195 protocol tests at source `64b7d280`.
[Preserved evidence](../evidence/index-integrity-2026-11-12/qualified-create-drop-followup/summary.json)
records source and scope. Final versioned-head checks are tracked separately in
[PR161](https://github.com/nikoma/bicdb/pull/161).

The source includes independently merged 1.0.485-beta metadata Append safety.
It does not include the queued ERP Decimal comparator or generic predicate
upgrade changes. Authenticated replicated table-rename recovery, partition DML
routing/default semantics, crash-durable SQL undo, the complete standalone
unique-index foreign-key dependency graph and final application/HA acceptance
are separate outstanding work. Source publication does not imply that a
binary, release or deployment was produced.
