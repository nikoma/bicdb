# BicDB 1.0.363-beta

This release opens BicDB under the Apache License, Version 2.0 and makes the
project easier for developers to evaluate, adopt, modify, and distribute.

- Replaces the active BUSL-1.1/AGPL transition with a prospective Apache-2.0
  grant for BicDB 1.0.363-beta and later releases.
- Adds the canonical Apache-2.0 text, a root NOTICE, SPDX package metadata, and
  matching license files in the browser package.
- Retires contradictory commercial-license and change-date material from the
  current distribution while preserving it in Git history and older tags.
- Reworks the README around concrete developer advantages, suitable first
  projects, honest limitations, and a clearer invitation to try BicDB.
- Keeps third-party licenses and attribution obligations explicit.

Earlier tagged releases remain governed by the license distributed with those
releases. This release does not retroactively alter their terms.
