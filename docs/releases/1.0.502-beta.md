# 1.0.502-beta: first positive data path for a registered fifth member

A registered fifth member can now receive one range and serve it. In the
in-process multi-node fixture, with real mutually authenticated sockets:

- the fifth installs the host writer policy and opens its data socket;
- the current voters take the source cut, and the image with full history is
  shipped into the fifth's installing state and verified there;
- the joint decision and staged membership changes make the fifth a voter and
  retire the old leader;
- the fifth becomes range leader and serves strong reads of the earlier rows
  and new writes, including with one original member stopped.

Limits of this version:

- a failure after the learner allocation commits leaves the range safe but
  unwritable; there is no abort back to the previous members, and resuming an
  interrupted transfer is not implemented;
- orchestration is driven by the test in one process; there is no production
  driver and no remote collector, and the new host methods have no production
  caller;
- a second range on the same member, cold restart and cleanup of the retired
  source are not exercised;
- the physical four-to-five node experiment has not been rerun.

See `docs/design/native-fifth-data-path.md`.
