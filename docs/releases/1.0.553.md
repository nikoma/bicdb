# 1.0.553: table page counts and index-only counts

## Added

- **ANALYZE records the average row size, and `pg_class.relpages` reports
  the resulting 8 KB page count.** No planner decision uses it yet.
  `relallvisible` stays 0, because there is no visibility map.
- **`count(*)` can be answered from a secondary B-tree index alone.** When the
  WHERE clause is exactly integer equalities on the leading columns of one
  secondary B-tree index, the count reads index entries and no rows. EXPLAIN
  shows it as an Index Only Scan. The route declines on primary-key indexes,
  standbys, repeatable-read snapshots and transactions with their own
  uncommitted writes, so every other case keeps the row-reading path.
