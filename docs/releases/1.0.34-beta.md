# BicDB 1.0.34-beta

Release date: 2026-08-03

## Bounded authenticated divergent-bucket export

- Adds authenticated cluster data protocol v14 export of one digest bucket from
  a completed node-owned range digest.
- Binds every request and response to the source member, range, epoch, digest
  session, bucket, and exact previous cursor.
- Revalidates the original durable write fence and resolved consensus prefix
  before and after every physical storage read, using destination-node time
  rather than a caller-asserted clock value.
- Streams checksummed, replayable frames under hard record, batch-byte,
  single-record, fanout, and cursor bounds.
- Advances through empty filtered batches without looping and validates strict
  record order, exact serialized byte counts, and token-bucket membership.
- Refuses missing, incomplete, symlinked, expired, stale, damaged, oversized,
  cross-bucket, and wrong-identity state or frames.
- Deliberately provides no write authority: repair still requires quorum-source
  evidence, bounded apply/delete semantics, and post-repair digest certification.
