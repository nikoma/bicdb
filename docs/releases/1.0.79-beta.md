# BicDB 1.0.79-beta

This release makes physical page traffic and page-file latency observable with
constant memory and metric cardinality, without trusting corrupt page contents.

## Physical page-class accounting

- Counts reads, writes, bytes read, and bytes written independently for
  superblock, heap, overflow, B+ tree interior, B+ tree leaf, and free pages.
- Charges short reads, checksum or torn-page failures, and invalid headers to a
  bounded `unclassified` class rather than classifying from untrusted bytes.
- Preserves aggregate counters and exposes class totals through the strict typed
  snapshot, operational metrics, Prometheus, doctor, and diagnostic bundles.
- Counts only completed positioned system calls. Pre-call injected failures and
  operating-system errors do not become completed I/O; successful partial
  transfers remain visible with their actual byte count.
- Rejects an unexpected short operating-system write as `ShortWrite` after
  recording the actual transfer, while retaining the explicit torn-write fault
  injector used to certify crash detection and recovery.

## Fixed latency evidence

- Measures positioned page reads, positioned page writes, and every successful
  page-file `sync_data`, including the mandatory tail-reclamation barrier.
- Exposes process-lifetime observation count, saturated total nanoseconds,
  maximum nanoseconds, and cumulative 1 us, 10 us, 100 us, 1 ms, 10 ms, 100 ms,
  1 s, 10 s, and infinity buckets.
- Keeps all boundaries non-configurable and exports fixed metric names without
  page, path, collection, index, tenant, query, or plugin labels.
- Leaves the small page-size discovery read outside the page-I/O counters and
  excludes checksum/decoding CPU time from physical I/O latency.

## Operational contract

- Advances the strict paged-storage snapshot format to version 6.
- Documents lock-free scrape semantics: aggregate, class, and latency totals
  converge exactly while I/O is quiescent and may differ by one or more
  concurrently completing operations during a live scrape.
- Keeps logical catalog/index/FTS/vector namespace attribution and sparse-file
  allocated-block accounting explicit as remaining roadmap work.

## Verification

Tests cover every supported physical page type, fixed bucket boundaries,
strict serialization, short and corrupt reads, failed and partial writes,
successful syncs, aggregate/class reconciliation while quiescent, doctor JSON,
fixed-cardinality Prometheus export, the complete page-storage suite, and every
workspace target.
