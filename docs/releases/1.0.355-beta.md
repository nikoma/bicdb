# BicDB 1.0.355-beta

This release makes BicDB's application contracts product-neutral.

- Renames the public application ABI, runtime, provider, Cell, SQL, and commit
  validation types from Carrier-specific names to generic `Application*`
  names.
- Replaces manifest fields such as `carrier_profile`, `carrier_program`,
  `carrier_request`, and `carrier_response` with canonical `application_*`
  fields.
- Keeps legacy serialized field and validator names readable through explicit
  deserialization aliases while emitting only the neutral canonical form.
- Renames the public application profile constant, execution entry points,
  host contracts, evaluation results, and runtime telemetry fields.
- Keeps Carrier Broker's own product API branded; the product adapts to the
  neutral BicDB contracts rather than defining them.
- Adds a compatibility regression test covering legacy input and canonical
  neutral output.

The repository remains under its existing license; this release does not
perform the proposed Apache-2.0 relicensing.
