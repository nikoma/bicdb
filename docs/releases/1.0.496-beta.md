# BicDB 1.0.496-beta

Adds the ordinary native program builtin `finance.units_limb(String, Int) -> Int`. It extracts one base10^14 limb at position0..5 from strictly canonical unsigned units below2^254, without application digit loops. It requires the signed `exact_unit_limb_access` feature. Older native manifests reject this feature; Cell and native invariant expressions do not admit the operation.

The operation grants no financial/source/tenant authority and changes no Decimal arithmetic, runtime budget, SQL behavior or accounting contract. Runtime and application qualification are separate from compiler admission.

Offline application CLI commands now restore the complete verified catalog without starting autonomous workers/schedules. Lifecycle plans still validate, and the existing quiescence gate remains mandatory. Serving runtimes retain ordinary supervisors; explicit worker commands retain their own authorization. This prevents restored background jobs from racing populated activation and prevents inspection/staging commands from executing business traffic.
